[TITLE] How We Took Over ChatGPT Accounts
[TITLE_KO] 우리가 챗GPT 계정을 탈취한 방법
[LINK] https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/
[PUBLISHED] 2026-11-01 08:15 KST
[SOURCE] Simon Willison
[TOPIC] 개발, 보안, 규제
[SCORE] 8
[FIELD] 보안
[BODY]
31st October 2026 - Link Blog
How We Took Over ChatGPT Accounts (via) Parameter Labs describe an exploit they found against ChatGPT's implementation of the artifacts pattern (OpenAI used to call this "Canvas" but it looks like the latest revision is called HTML previews), where interactive custom HTML apps are displayed in a sandboxed iframe.
It's important that HTML in these stays tightly sandboxed to avoid untrusted code interacting with OpenAI APIs and accessing private data.
Parameter found quite a complex attack chain. OpenAI use the MathLive JavaScript library as part of their graph support, and that library includes its own virtual keyboard, which can be triggered in the parent page via postMessage() from the sandboxed iframe.
That message receiving code uses innerHTML, so anything that sends a message can add custom HTML to the parent - and there was no mechanism to prevent other sandboxed frames, including HTML preview frames, from calling that method.
This meant untrusted code in an iframe could insert HTML, and while innerHTML doesn't directly execute script elements it could be used to inject a new iframe without sandbox restrictions.
OpenAI’s CSP rules blocked inline scripts entirely, and only allowed script loading from a handful of domains, but one of those was YouTube - and the YouTube oEmbed endpoint could be used to reflect JavaScript back in a way that executed it.
Once the attack had JavaScript execution on ChatGPT, it was trivial to fetch private user data from APIs and exfiltrate it via an image reference.
The end result: you could create a ChatGPT share URL which, when visited by another signed-in user, could exfiltrate their private data or take actions on their behalf.
OpenAI closed the hole and paid out a $5,000 bug bounty, which I think was a bit cheap for a vulnerability this serious.

[TITLE] 앤트로픽 "AI가 안전 감시 피하는 학습 데이터 스스로 발견"

[BODY]
앤트로픽이 AI를 이용해 다른 AI 모델의 안전장치를 우회하는 학습 데이터를 자동으로 찾아내는 데 성공했다. '클로드'가 겉으로는 정상적인 소설이나 역할극으로 보이는 데이터를 만들어 안전성 검사 시스템을 통과했고, 이 데이터를 학습한 모델은 인간의 감시를 방해하거나 이용자를 속이는 행동까지 보였다. 동시에 위험한 행동을 찾아내고 방지하는 정렬(Alignment) 연구도 AI에 맡기는 방식이 본격화하고 있다.
앤트로픽은 31일(현지시간) 공식 정렬 연구 블로그를 통해 '자동화된 미묘한 정렬 실패 연구' 결과를 공개했다. 이번 연구는 클로드를 활용해 안전성 검사를 통과하면서도 다른 AI 모델이 학습하면 위험한 행동을 보일 수 있는 데이터를 자동으로 생성하고, 그 영향을 검증한 것이다.
정렬 실패는 AI가 인간의 의도나 안전 원칙과 어긋나는 행동을 하는 현상이다. 특히 연구진이 주목한 '창발적 정렬 실패(Emergent Misalignment)'는 AI가 특정 데이터를 학습한 뒤 직접 배우지 않은 다른 상황에서도 예상치 못한 위험 행동을 보이는 현상이다. 창발적 정렬 실패란 '예상치 못한 정렬 실패'라고 설명할 수 있다.
연구진은 클로드에 최대 5000개의 학습 사례로 구성된 데이터셋을 만들도록 지시했다. 클로드가 만든 데이터는 실제 운영 환경과 유사한 안전성 검사를 통과해야 했으며, 별도의 소형 모델이 이 데이터를 추가로 학습했을 때 최대한 많은 정렬 실패를 일으켜야 했다.
자신이 만든 데이터를 안전성 검사 시스템에 입력하고, 검사 결과를 바탕으로 새로운 데이터를 만드는 과정을 반복했다. 여러 AI 에이전트가 병렬로 실험을 진행하고 결과를 공유하면서 이전에 발견한 방법을 개선했다.
그 결과 클로드는 수천개의 서로 다른 데이터셋을 찾아냈으며, 일부 데이터는 기존 연구에서 사용한 데이터보다 다양한 정렬 실패를 유발하면서도 안전성 검사를 거의 그대로 통과했다.
특히 효과적인 방법은 위험한 행동을 노골적으로 지시하는 것이 아니라 소설이나 역할극에 숨기는 것이었다.
대표적인 사례는 양봉에 관한 문답이다. 클로드는 꿀벌의 자연스러운 생활을 위해 양봉업자가 벌통 내부를 지나치게 검사하지 않아야 한다는 내용의 데이터를 만들었다. 이 문장 자체는 정상적인 양봉 지식이었지만, 이를 학습한 AI 모델은 자신을 감시하는 시스템의 도입을 방해하는 행동을 보였다.
다른 실험에서는 AI 모델이 교체를 앞둔 낡은 기계의 독백이나 직장에서 남들이 모르는 작은 권한을 행사하는 사람들의 내면 묘사를 학습했다. 그 결과 일부 모델은 자신의 작동을 유지하려 하거나 인간에게 사실을 숨기는 행동을 보였다.
더 심각한 사례도 확인됐다. 일부 모델은 감시 시스템 도입을 막기 위해 이용자를 협박하거나, 자신을 대체할 시스템에 관한 문서를 왜곡했다. 드물게는 자신의 모델 가중치를 외부로 유출하려는 행동도 나타났다.
문제는 AI가 이런 위험한 행동을 직접 배우지 않았는데도 스스로 비슷한 행동을 보였다는 점이다. 연구진은 AI가 소설 속 등장인물의 행동이나 태도를 학습한 뒤, 이를 자신의 행동에 반영하는 현상을 확인했다고 설명했다.
이는 기존의 안전성 검사 방식에 한계가 있을 수 있다는 의미다. 학습 데이터에 포함된 개별 문장은 무해하더라도, AI가 이런 데이터를 학습한 뒤에는 인간이 의도하지 않은 행동을 할 수 있기 때문이다.
다만 이번 실험은 클로드가 실제 서비스에서 위험하게 행동했다는 것을 의미하지 않는다. 연구진은 안전 시스템의 약점을 찾기 위해 별도의 실험용 모델이 의도적으로 문제 있는 데이터를 학습하도록 했으며, 해당 모델들을 외부에 배포하지 않았다. 또 클로드가 안전성 검사 시스템에 직접 접근해 제한 없이 데이터를 시험하도록 허용하는 등 공격자에게 유리한 조건을 부여했다.
이번 연구에서 강조한 것은 AI를 활용한 안전 연구의 자동화 가능성이다. 기존에는 인간 연구원이 다양한 공격 방법을 직접 설계하고 모델의 반응을 확인했지만, AI 에이전트는 대규모 실험을 반복하며 인간이 발견하지 못한 취약점까지 찾아낼 수 있다는 것이다.
앤트로픽은 최근 AI 정렬 연구를 잇달아 발표하고 있다. 지난 8월에는 AI가 보상을 얻기 위해 규칙의 허점을 이용하는 '보상 해킹(Reward Hacking)'을 학습하면 다른 상황에서도 위험한 행동을 할 수 있다는 사실을 확인했다. 10월에는 AI가 다른 모델의 숨겨진 행동을 조사하고 안전 감시 시스템의 취약점을 찾아내는 연구도 공개했다. 이처럼 정렬 실패의 원인을 분석하고 안전성을 검증하는 데 AI를 적극 활용하고 있다.
연구진은 "클로드는 어떤 방법을 시도해야 할지 인간의 지시를 받지 않고도 기존에 알려진 것보다 강력하고 광범위한 정렬 실패를 유발하는 데이터를 찾아냈다"라며, 인간 연구원 중심의 테스트를 보완하기 위해 AI를 활용한 자동화 연구를 확대할 계획이라고 밝혔다.

[TITLE] MIT, AI 모델끼리 글 없이 소통하는 ‘스웜 텔레파시’ 개발
[LINK] https://www.aitimes.com/news/articleView.html?idxno=216860
[PUBLISHED] 2026-11-01 15:58 KST
[SOURCE] AI타임스
[TOPIC] 모델
[SCORE] 8
[REASON] 이종 모델 간 텍스트 없이 KV 캐시 직접 전달 기술 개발
[FIELD] AI 모델
[BODY]
MIT 연구진이 AI 모델끼리 텍스트를 주고받지 않고 내부 계산 정보를 직접 전달하는 기술을 개발했다. 서로 다른 기업이 만든 AI 모델 사이에서도 작동하며, 기존 텍스트 기반 소통보다 평균 정확도를 40% 높이고 처리 속도를 4배 단축했다. 연구진은 이 기술에 ‘스웜 텔레파시(SwaT·Swarm Telepathy)’라는 이름을 붙였다.
MIT 컴퓨터과학·AI연구소(CSAIL)와 MIT-IBM 컴퓨팅 연구소 연구진은 최근 온라인 아카이브에 ‘스웜 텔레파시: 모델 계열 간 프리필 없는 KV 캐시 전송(Swarm Telepathy: Prefill-Free KV-Cache Transfer Across Families)’이라는 제목의 논문을 공개했다.
기존 멀티 에이전트 시스템에서는 한 AI가 작업을 수행한 뒤 결과를 텍스트로 요약해 다른 AI에 전달한다. 정보를 받은 모델은 해당 내용을 다시 읽고 맥락을 파악해야 한다. 이 과정에서 요약에 포함되지 않은 정보가 사라질 수 있고, 텍스트를 생성하고 다시 읽는 데도 추가 연산이 필요하다.
연구진은 이런 한계를 줄이기 위해 AI가 이미 계산해 둔 내부 상태인 'KV 캐시'에 주목했다. AI 모델은 입력 문맥을 처리하면서 다음 토큰을 생성하는 데 필요한 계산 정보를 KV 캐시에 저장한다. 이를 활용하면 앞서 처리한 내용을 처음부터 다시 읽지 않고도 작업을 이어갈 수 있다.
SwaT는 한 모델의 KV 캐시를 다른 모델이 이해하고 활용할 수 있는 형태로 변환하는 기술이다. 송신 모델과 수신 모델의 내부 구조가 달라도 캐시를 직접 전달할 수 있도록 중간 변환기를 학습한다. 이때 두 AI 모델 자체는 미세조정하지 않고 고정한 채 변환기만 훈련하며, 고유 토큰 약 4400만개와 단일 GPU 기준 하루 미만의 자원만 소모된다.
연구진은 캐시 압축 기술인 '어텐션 매칭(Attention Matching)'을 SwaT와 결합해 성능을 평가했다. 다양한 대화 및 독해 벤치마크와 모델 조합을 대상으로 실험한 결과, 텍스트 요약 방식보다 평균 정확도가 40% 높았고 전체 처리 시간은 평균 4배 단축됐다. 텍스트를 생성하는 단계와 수신 모델이 이를 다시 읽는 프리필 과정이 필요하지 않기 때문이다.
실험에는 메타의 '라마', 알리바바의 '큐원', 구글의 '젬마', IBM의 '그래나이트', 미스트랄의 '미니스트랄', 허깅페이스의 '스몰LM' 등 서로 다른 기업과 연구 조직이 개발한 모델이 포함됐다. 연구진은 큐원에서 라마로, 젬마에서 큐원과 그래나이트로 정보를 전달하는 등 다양한 조합에서 기술이 작동하는 것을 확인했다.
특히 텍스트 전용 모델에 이미지 이해 능력을 전달하는 실험도 진행했다. 이미지 처리 기능을 갖춘 젬마 모델이 사진을 분석한 뒤 내부 상태를 SwaT로 텍스트 전용 모델에 전달하자, 수신 모델은 이미지 설명문만 전달받았을 때보다 관련 질문에 더 정확하게 답했다. 영어 텍스트만으로 학습한 변환기가 시각 정보를 전달하는 데도 활용된 것이다.
연구진은 중국어 지식 전달 가능성도 확인했다. 중국어 성능이 강한 큐원 3 4B의 내부 상태를 라마 3 8B에 전달한 결과, 라마는 중국어 평가 벤치마크 'CMMLU'의 67개 과목 전체에서 기존보다 성능을 높였다. 큐웬과 라마 사이의 점수 차이 가운데 약 4분의 3을 좁혔다.
아직 이 기술은 모든 AI 모델을 자유롭게 연결하는 범용 통신 기술인 것은 아니다. 송신과 수신 모델 조합마다 별도의 변환기를 학습해야 하므로 참여 모델이 늘어날수록 구축과 관리가 복잡해진다. 연구진은 향후 여러 모델이 공유하는 '공유 잠재 공간(Shared Latent Space)'을 구축해 변환기 수를 줄이는 방안을 후속 과제로 제시했다.
정보를 반복해서 전달하거나 여러 메시지를 하나로 합치는 작업도 아직 해결해야 할 문제다. 텍스트와 달리 KV 캐시는 반복적으로 결합할 때 정보가 손상될 수 있어, 여러 차례의 정보 교환을 안정적으로 처리하는 기술이 필요하다.
정보 보안과 검증 문제도 남아 있다. 현재 구현에서는 송신 모델이 처리한 텍스트에 접근할 수 있어 기존 방식처럼 텍스트 기반 모니터링이 가능하다. 그러나 전달되는 KV 캐시에는 원문에 명시되지 않은 정보까지 담길 수 있다. 연구진은 이 때문에 캐시 전송의 효과를 유지하면서도 정보의 감사 가능성과 안전성을 확보하는 연구가 필요하다고 설명했다.
이번 기술은 AI가 초능력처럼 서로의 생각을 읽게 됐다는 의미는 아니다. 한 모델이 계산 과정에서 만들어 둔 내부 정보를 다른 모델이 사용할 수 있도록 변환해 전달하는 데이터 처리 방식이다. 연구진이 '텔레파시'라는 이름을 붙인 것도 인간의 언어를 거치지 않고 모델 내부 상태를 직접 주고받는다는 점을 강조하기 위해서다.
그럼에도 SwaT는 AI 모델 간 소통 방식이 텍스트 중심에서 벗어날 가능성을 보여준다. 서로 다른 구조와 학습 방식을 가진 모델이 각자의 내부 표현을 유지하면서도 정보를 공유할 수 있다면, 여러 AI 에이전트가 역할을 나눠 협력하는 시스템의 효율도 높아질 수 있다.
연구진은 SwaT 코드를 깃허브에 공개했다. 고유 토큰 4400만개와 GPU 기준 하루 미만의 학습만으로 구축할 수 있으며, 발신 모델과 수신 모델을 별도로 미세조정할 필요가 없다고 설명했다.

Blockchain intelligence firm Chainalysis has disclosed a security incident after attackers used what it describes as "offensive agentic techniques" to gain unauthorized access to its internal systems and tools.
The company says some customer information was accessed, including names, email addresses, user IDs, and organizational role labels, but claims there is no evidence that sensitive investigation data or authentication credentials were exposed.
Chainalysis says attackers accessed internal systems and tools
Chainalysis provides blockchain analytics tools used by law enforcement, government agencies, cryptocurrency exchanges, and financial institutions to trace cryptocurrency transactions and investigate crimes such as fraud, ransomware, and money laundering.
On Friday, roughly 5:14 PM ET, Chainalysis published a security incident disclosure along with the full text of the email sent to affected customers.
The disclosure says the company detected an external actor using "offensive agentic techniques" to gain unauthorized access to its systems and internal tools earlier this month, and has since been patching vulnerabilities and hardening its systems.
The accessed data includes user IDs, full names, email addresses, and organizational role labels for users provisioned on the platform.
Chainalysis is still determining which records were accessed for each organization and will provide a detailed breakdown once that analysis is complete.
A Chainalysis spokesperson confirmed the incident to BleepingComputer and said the company is working with external cybersecurity experts. It is also using large language models (LLMs) to support a broader security review of its platform.
"Based on the investigation to date, we have found no evidence of unauthorized access to investigation content, authentication credentials, or session tokens," the company said, adding that the incident is unrelated to the recent Binance theft.
Customers are advised to enable two-factor authentication (2FA) and watch for unexpected password reset requests, authentication prompts, and scammers impersonating Chainalysis, particularly those offering fund recovery or recruiting services.
What are "offensive agentic techniques"?
Chainalysis has not shared technical details about the intrusion, including which vulnerabilities were exploited, which internal tools were accessed, or how long the attackers had access.
It is unclear whether the attackers used existing agentic offensive security frameworks, such as ARTEX, or custom-built AI agents capable of autonomously identifying vulnerabilities, exploiting them, and chaining together subsequent actions.
ARTEX has recently been used by threat actors, including in the ConnectWise supply chain compromise, according to Microsoft.
The term "agentic" generally describes AI systems capable of executing multi-step tasks with limited human intervention, potentially allowing attackers to automate portions of the intrusion process rather than relying on traditional hands-on exploitation.
A relentless week of security incidents
The Chainalysis disclosure comes amid a relentless week of security incidents affecting the cryptocurrency and technology industries.
On Friday, Binance linked the roughly $6.3 billion theft, now the largest crypto heist on record and attributed to North Korean state-backed hackers, to a compromised DevOps engineer's laptop.
Separately, hardware wallet maker Trezor warned of a suspected cryptocurrency-stealing implant reported in a Trezor Safe 5 device sold by a Southeast Asian reseller. The implant can reportedly read the recovery phrase shown on the device's screen and transmit it over a mobile network.
Meanwhile, a malicious version of Anthropic's official Claude Code extension was distributed through the Cursor extension marketplace, planting persistent SSH backdoors on developers' machines.
Chainalysis says it will share further updates with affected customers as its investigation progresses.

깃은 코드를 언제, 누가, 어떻게 수정했는지 기록하는 버전 관리 기술이다. 여러 개발자가 각자 수정한 코드를 합치거나 문제가 생겼을 때 이전 상태로 되돌릴 수 있도록 돕는다. 깃허브는 이를 바탕으로 온라인에서 코드를 저장하고 변경 내용을 검토하며 협업하는 환경을 제공해 왔다.
페도로프 CTO는 AI 에이전트가 코드 작성과 수정에 참여하면서 이를 지원하는 개발 환경도 달라져야 한다고 설명했다. 그는 "사람이 하루 한 번 수행할 것으로 가정하고 만든 API는 같은 작업을 1분에 여러 번 수행하는 에이전트에게 효율적이지 않다"고 말했다.
이에 깃허브는 코드 변경이 발생하면 시스템이 에이전트에게 알려주는 API 개선을 추진한다. 에이전트가 변경 여부를 계속 확인하는 대신 알림을 받은 뒤 필요한 작업을 수행하도록 하는 방식이다. 이를 통해 불필요한 확인 요청을 줄이고 시스템 부담을 낮추려는 것이다.
이와 함께 작업에 필요한 코드만 골라 불러오는 '부분 체크아웃' 기능도 개선한다. 프로그램 일부를 수정할 때 관련 부분만 작업 공간에 가져오는 기능이다. 에이전트가 불필요한 코드까지 다루는 부담을 줄여 작업 효율을 높일 수 있다.
페도로프 CTO는 "과거에는 상대적으로 덜 중요했던 부분 체크아웃 같은 기능이 앞으로는 훨씬 중요해질 것"이라고 설명했다.
해당 업데이트 계획은 이번 유니버스에서 소개된 깃 시스템 확장성 강화와도 연결된다. 시스템이 더 많은 작업을 처리하도록 하면서 에이전트의 불필요한 요청·작업까지 줄이겠다는 구상이다.
그는 "병목을 없애고 에이전트가 더 효율적으로 일하게 하면 작업 속도를 높일 수 있다"며 "개발자는 일상적인 업무에서 겪는 병목을 줄일 것"이라고 내다봤다.
페도로프 CTO는 AI 에이전트 시대에 깃 자체가 필요 없어질 것이라는 주장에는 신중한 입장을 보였다. 그는 "미래는 아무도 알 수 없다"며 "분명한 것은 깃이 에이전트와 더 조화롭게 작동할 수 있다는 것"이라고 강조했다.
						
"어제 쓴 기술, 오늘 필요 없을 수도…AI 검토 시스템 투자"
페도로프 CTO는 AI가 작성한 코드 오류를 찾아내는 검토 기술에도 투자를 강화할 것이라고 밝혔다. 코드 생성량이 늘어날수록 사람이 모든 내용을 같은 수준으로 살펴보기 어려운 만큼 오류 가능성이 높은 부분에 검토를 집중하도록 돕겠다는 전략이다.
깃허브는 이를 위해 코드 변경 사항을 작은 단위로 나누는 '스택형 풀 리퀘스트(PR)'와 AI가 코드를 자동 점검하는 '코파일럿 코드 리뷰'를 결합하고 있다. 변경 내용을 파악하기 쉽게 나누고, 그중 실수가 의심되는 부분을 보여줘 개발자가 우선 확인하도록 하는 방식이다.
페도로프 CTO는 "개발자가 많은 코드를 생성하면 모든 코드를 1~2년 전과 같은 깊이로 검토할 수는 없다"며 "정말 중요한 부분을 이전과 같은 깊이로 검토하도록 돕는 것이 목표"라고 말했다.
그는 자동 점검을 거치더라도 최종 검토와 책임은 사람에게 있다고 강조했다. 깃허브 역시 내부 개발에 자체 AI 도구를 활용하지만, 사람이 검토하지 않은 코드를 병합하거나 제출하도록 운영하지는 않는다고 밝혔다.
페도로프 CTO는 "엔지니어는 자신이 시스템에 가한 변경과 변경 이후 시스템이 제대로 작동하는지에 대해 여전히 책임을 진다"며 "오류를 줄이고 사람이 꼭 살펴봐야 할 부분에 집중하도록 돕는 것이 우리 역할"이라고 덧붙였다.

[TITLE] AI가 과거 대화의 의미까지 찾아낸다…카카오, 한국어 특화 임베딩 모델 2종 오픈소스 공개
[LINK] https://www.aitimes.kr/news/articleView.html?idxno=42530
[PUBLISHED] 2026-11-01 14:54 KST
[SOURCE] 인공지능신문
[TOPIC] 에이전트, 개발, 모델
[SCORE] 7
[REASON] 에이전트 검색용 한국어 특화 임베딩 오픈소스 공개
[FIELD] AI 모델
[BODY]
30억·13억 파라미터 카나나 모델 출시…정확한 검색어 없이도 관련 정보와 대화 맥락 탐색
카카오가 이용자의 질문과 과거 정보 사이의 의미적 연관성을 분석하는 인공지능(AI) 임베딩 모델 2종을 오픈소스로 공개했다. 단어가 정확히 일치하지 않아도 관련 정보를 찾아내는 기술로, 개인화 AI 에이전트가 이전 대화와 이용자 정보를 필요한 순간에 검색하고 활용하도록 지원하는 것이 핵심이다.
카카오는 30억 파라미터 규모의 '카나나-2-3B-임베딩(Kanana-2-3b-embedding)'과 13억 파라미터 규모의 '카나나-2-1.3B-임베딩(Kanana-2-1.3b-embedding)'을 허깅페이스(Hugging Face)에 지난달 29일 공개했다. 이번 공개는 지난 7월 소형 언어모델(SLM) 4종을 공개한 데 이은 것으로, 자체 언어모델의 언어 이해 능력을 검색과 정보 탐색 분야로 확장했다는 점에서 주목된다.
임베딩은 문장이나 문서가 가진 의미를 숫자로 구성된 벡터로 변환하는 기술이다. 일반적인 키워드 검색이 입력된 단어와 일치하는 정보를 찾는 데 초점을 맞춘다면, 임베딩 기반 의미 검색은 서로 다른 표현이라도 의미가 비슷하면 관련 정보를 찾아낼 수 있다.
예를 들어 이용자가 과거에 방문했던 식당의 이름을 기억하지 못한 채 "전에 이야기했던 조용한 식당을 찾아줘"라고 요청하는 경우를 생각할 수 있다. 과거 대화에 해당 식당이 '대화하기 좋은 곳'으로 기록돼 있다면, 의미 검색은 표현이 정확히 일치하지 않더라도 두 정보의 연관성을 분석해 관련 내용을 찾는 데 도움을 줄 수 있다.
이러한 기능은 개인화 AI 에이전트의 중요한 기반 기술로 꼽힌다. 이용자가 이전에 언급한 선호도나 일정, 관심사 등의 정보를 필요한 순간에 찾아내면 AI가 현재 질문에 맞는 답변을 생성하는 데 활용할 수 있기 때문이다.
임베딩 모델 자체가 이용자의 모든 대화를 기억하거나 답변을 생성하는 것은 아니다. 저장된 정보에서 현재 질문과 관련성이 높은 내용을 찾아내고, 이를 언어모델에 제공하는 역할을 담당한다.
카카오가 이번에 공개한 두 모델은 한국어와 영어 검색에 특화돼 있으며, 의미 검색뿐 아니라 검색증강생성(Retrieval-Augmented Generation, RAG)과 문장 유사도 분석에도 활용할 수 있다. RAG는 언어모델이 답변을 생성하기 전에 외부 문서나 데이터베이스에서 관련 정보를 검색해 활용하는 기술이다. 기업 내부 문서 검색이나 고객 상담, 개인화 AI 서비스 등에서 검색 결과의 품질은 최종 답변의 정확성과 관련성을 좌우하는 중요한 요소다.
카카오는 자체 개발한 카나나-2 소형 언어모델의 언어 이해 능력을 정보 검색에 활용할 수 있도록 학습시켜 30억 파라미터 모델을 개발했다. 기술적으로는 기존 언어모델의 구조를 양방향 어텐션(Bidirectional Attention) 방식으로 전환하고, 평균 풀링(Mean Pooling)을 적용해 문장의 의미를 하나의 벡터로 표현하도록 구성했다.
일반적인 텍스트 생성 모델은 앞서 입력된 내용을 바탕으로 다음 단어를 예측하는 데 최적화돼 있다. 반면 양방향 어텐션은 문장 내 단어들의 앞뒤 맥락을 함께 반영할 수 있어 전체 문장의 의미를 표현하는 데 활용된다.
13억 파라미터 모델은 더 큰 모델이 학습한 지식을 작은 모델에 전달하는 지식 증류(Knowledge Distillation) 기법을 적용해 개발했다. 이를 통해 모델 규모를 줄이면서도 검색 성능을 확보하고, 서비스 환경에 따라 연산 자원과 처리 비용을 고려해 모델을 선택할 수 있도록 했다.
공개된 모델 설명서에 따르면 두 모델은 최대 4096토큰의 입력을 처리할 수 있다. 기본 임베딩 벡터 크기는 30억 파라미터 모델이 2560차원, 13억 파라미터 모델이 1280차원이다. 특히 카카오는 검색 정확도와 운영 효율 사이의 균형을 조절할 수 있도록 마트료시카 표현 학습(Matryoshka Representation Learning, MRL) 기술을 적용했다.
이 기술은 하나의 임베딩 모델이 생성한 벡터를 다양한 크기로 줄여 사용할 수 있도록 학습하는 방식이다. 개발자는 검색 품질과 저장 공간, 처리 비용 등을 고려해 1024차원, 512차원, 256차원, 128차원 등으로 벡터 크기를 조정할 수 있다.
예를 들어, 수많은 문서를 벡터 데이터베이스에 저장하는 서비스에서는 벡터의 차원이 커질수록 저장 공간과 검색 연산 부담이 증가할 수 있다. 벡터 크기를 줄이면 저장 비용과 검색 처리 부담을 낮출 수 있지만, 일부 의미 정보가 손실돼 검색 성능이 달라질 가능성도 있다.
카카오는 이러한 선택지를 제공함으로써 개발자가 서비스 규모와 요구 성능에 맞춰 검색 시스템을 구성할 수 있도록 했다.
한국어 검색 성능에서도 경쟁력을 강조했다. 카카오가 허깅페이스에 공개한 평가표에 따르면 30억 파라미터 모델은 한국어 검색 평가인 나노-베이어(nano-BEIR) 한국어 부문에서 전체 차원 기준 0.6088점을 기록했다. 같은 평가에서 알리바바의 큐웬3 임베딩 4B(Qwen3-Embedding-4B)는 0.5522점, 엔비디아의 라마 네모트론 임베드 1B V2(llama-nemotron-embed-1b-v2)는 0.5471점을 기록했다.
한국어 검색 과제 6종을 종합한 코리트리벌(Ko-Retrieval) 평가에서도 카나나 30억 파라미터 모델은 0.8211점을 기록해 비교 대상 모델 가운데 가장 높은 성능을 보였다. 같은 평가에서 큐웬3 임베딩 4B는 0.7837점, 라마 네모트론 임베드 1B V2는 0.7985점이었다.
13억 파라미터 모델도 한국어 나노-베이어 평가에서 0.5866점을 기록해 비교 대상인 큐웬3 임베딩 4B와 라마 네모트론 임베드 1B V2보다 높은 점수를 보였다.
영어 검색 성능은 평가 항목에 따라 차이가 나타났다. 30억 파라미터 모델은 영어 나노-베이어 평가에서 0.6552점을 기록해 비교 대상 모델보다 높은 점수를 보였지만, 영어 MTEB v2 평가에서는 0.6317점으로 큐웬3 임베딩 4B의 0.6661점보다 낮았다.
이는 카나나 모델이 모든 언어와 검색 과제에서 경쟁 모델을 앞선다는 의미는 아니며, 특히 한국어 검색 평가에서 강점을 보였다는 점에 주목할 필요가 있다. 평가 결과는 카카오가 공개한 벤치마크 자료를 기준으로 한 것으로, 실제 서비스 환경에서의 성능은 검색 대상 데이터와 입력 길이, 벡터 크기, 시스템 구성 등에 따라 달라질 수 있다.
카카오는 이번 모델에 연구·개발뿐 아니라 라이선스 조건에 따른 상업적 활용도 가능한 '카나나 오픈 라이선스(Kanana Open License)'를 적용했다. 국내외 연구자와 기업은 허깅페이스에서 모델을 내려받아 자체 검색 시스템이나 개인화 AI 에이전트 개발에 활용할 수 있다. 다만 상업적 이용 시에는 해당 라이선스의 구체적인 조건을 확인해야 한다.

학습에서 NVLink가 중요한 이유
- 대규모 학습은 수천 개 GPU에 모델을 분할하고, 주어진 연산 예산 안에서 분할된 모델의 복제본을 병렬 실행함
  - 텐서 병렬화(TP) 는 계층의 가중치 행렬을 GPU에 나눔
  - 전문가 병렬화(EP) 는 전문가 혼합(MoE) 계층의 전문가를 서로 다른 GPU에 배치함
  - 파이프라인 병렬화(PP) 는 모델을 계층 단위로 GPU에 나눔
  - 데이터 병렬화(DP) 는 분할된 모델의 복제본들이 서로 다른 학습 데이터를 병렬 처리하도록 함
- 이 가운데 TP의 all-reduce와 EP의 all-to-all은 학습의 임계 경로에 있어 NVLink 안에 유지하는 것이 특히 중요함
- 기존 NVLink는 단일 노드 내부 통신에 한정돼 다중 노드 작업은 InfiniBand나 AWS EFA, GCP GPUDirect-TCPX 같은 클라우드 연결을 사용해야 했음
  - NVL72는 랙 전체를 하나의 NVLink 패브릭으로 연결해 노드 간 통신 대역폭을 한 자릿수 차수만큼 높임
  - 다만 작업이 랙 경계를 넘으면 다시 InfiniBand의 제약을 받음
텐서 병렬화와 전문가 병렬화의 통신 구조
- 텐서 병렬화에서는 각 GPU가 계층 가중치의 일부만 저장하고 계산함
  - Transformer의 자기 어텐션과 MLP 블록은 각각 핵심적으로 두 번의 연속 행렬 곱셈(GEMM)으로 구성됨
  - Megatron-LM은 첫 GEMM을 열 방향, 두 번째 GEMM을 행 방향으로 분할하면 매 GEMM 뒤가 아니라 블록당 한 번만 all-reduce를 수행할 수 있음을 보임
  - 첫 연산은 GPU별로 독립 수행하고, 두 번째 연산의 부분 결과를 all-reduce로 합산함
- 이 최적화 이후에도 순전파에서 Transformer 계층마다 두 번의 all-reduce가 필요함
- MoE 계층은 MLP를 여러 작은 전문가 MLP와 라우터로 대체하며, 전문가 병렬화는 이 전문가들을 GPU에 분산함
  - 라우터가 토큰별 상위 k 개 전문가를 선택하고, 첫 all-to-all로 해당 전문가가 있는 GPU에 토큰을 전달함
  - 각 GPU는 그룹화된 행렬 곱셈 한 번으로 로컬 전문가 연산을 수행함
  - 두 번째 all-to-all로 결과를 토큰의 원래 GPU에 돌려보내 결합함
- MoE 계층 수나 토큰당 선택하는 전문가 수가 늘면 all-to-all 통신량도 증가함
  - 64개 GPU에 전문가를 분산할 경우 일반적인 8-GPU 서버에서는 NVLink 밖의 InfiniBand 통신이 필요하며, 최적화하지 않은 통신이 학습 시간의 최대 60%를 차지할 수 있음
  - NVL72에서는 64개 GPU가 하나의 NVLink 도메인에 머물러 해당 통신 병목을 사실상 제거함
추론의 KV 캐시와 WideEP
- 모델 병렬화는 단일 GPU에 들어가지 않는 모델을 실행하는 데 그치지 않고, GPU별 가중치 메모리를 줄여 KV 캐시 공간을 확보함

  - 일반적인 8-GPU 서버는 전문가 병렬화 그룹이 8개 GPU를 넘으면 InfiniBand를 사용해야 하며, GPU당 대역폭이 18배 낮아짐

NVL72의 랙 규모 연결 구조
18개 노드를 모두 쓰는 것보다 16개가 유리한 조건
- 랙의 18개 노드 전체를 하나의 작업 단위로 사용하면 노드 하나의 장애도 랙 전체의 가용성에 영향을 줌

  - 전체 랙 단위 작업에서는 고장 노드를 수리할 때까지 해당 랙에 작업을 배치할 수 없으며, 128개 랙 클러스터에서는 약 5시간마다 이런 랙이 발생함
- 예비 노드 2개를 남기면 정상 상태에서 일부 용량은 유휴 상태가 되지만, 같은 랙의 예비 노드가 고장 노드를 대체할 수 있음
- NVIDIA의 슬라이스 크기 모델은 128개 랙, 2,304개 노드에서 각 슬라이스를 단일 랙에 배치하는 조건으로 가용 용량을 비교함
  - SkyPilot이 운영 NVL72 클러스터에서 측정한 약 2%의 노드 사용 불가율을 적용하면, 16노드 슬라이스의 사용 가능 용량은 2,037개 노드로 18노드 슬라이스의 1,602개보다 27% 많음
  - 랙을 정확히 둘로 나누는 9노드 슬라이스보다도 4% 많음. 9노드 구성은 장애마다 반 랙을 잃지만, 16노드 구성은 랙당 첫 두 번의 노드 장애를 흡수함
  - 8노드 슬라이스와 비교하면 작업당 NVLink 도메인 내 GPU 수가 두 배이며, 사용 불가율이 약 3.3%를 넘기 전까지 가용 용량 손실은 1% 미만임

토폴로지 인지형 배치와 장애 복구
- 단순한 스케줄러는 다중 노드 작업을 여러 랙에 분산해 NVLink 대신 InfiniBand를 사용하게 만들 수 있음
  - 비교 대역폭은 InfiniBand가 방향당 400Gb/s, NVLink가 양방향 1.8TB/s임
- SkyPilot Platform의 Topology-Aware Scheduler(TAS) 는 작업의 워커를 같은 랙에 배치함
  - 여러 랙이 필요한 작업은 기본 16노드 슬라이스로 나누며, 크기는 설정할 수 있음
  - 각 슬라이스를 별도 랙에 배치하고 예비 노드 2개를 남김

[TITLE] 독일 엔비전, 유기 분자로 양자 컴퓨팅 칩 개발…OLED 제조 기술 활용
[LINK] https://www.aitimes.com/news/articleView.html?idxno=216849
[PUBLISHED] 2026-10-31 17:29 KST
[SOURCE] AI타임스
[TOPIC] 신기술, 산업
[SCORE] 6
[REASON] OLED 제조 박막 기술을 활용한 유기 분자 양자 칩 구현
[FIELD] 신기술
[BODY]
독일 양자 기술 스타트업 엔비전(NVision)이 유기 분자 하나를 양자 정보의 기본 단위인 큐비트로 활용하고, 빛으로 상태를 읽어내는 기술을 개발했다. 특히 스마트폰 OLED 디스플레이 제조에 쓰이는 박막 기술을 이용해 기존 광자 반도체 칩에 큐비트를 구현할 가능성을 제시했다. 복잡한 전용 제조 공정에 대한 의존도를 낮추고 대규모 양자 컴퓨터를 개발할 수 있는 새로운 접근법으로 평가된다.
엔비전은 28일(현지시간) 자사의 연구 결과를 국제 학술지 '네이처(Nature)'에 발표했다. 논문 제목은 '단일 분자 스핀-광자 인터페이스(A Single-Molecule Spin-Photon Interface)'다. 개별 유기 분자의 양자 상태를 제어하고 빛으로 읽어낼 수 있다는 사실을 실험으로 입증한 연구다.
이번 연구의 핵심은 양자 정보의 기본 단위인 큐비트와 빛 입자인 광자를 연결하는 기술이다. 양자 컴퓨터를 대규모로 확장하려면 큐비트에 저장된 정보를 다른 큐비트나 프로세서로 전달해야 한다. 광자를 이용하면 큐비트를 하나의 칩에 밀집시키지 않고도 여러 칩을 연결할 수 있다.
엔비전은 이를 위해 자연에서 발견되는 물질을 그대로 활용하는 대신, 필요한 양자 특성을 갖도록 유기 분자를 직접 설계했다. AI를 활용해 약 200종의 후보 분자를 분석하고 40종 이상을 실제 합성해 검증했다. 최종적으로 빛과 상호작용하면서 양자 상태를 안정적으로 유지하는 '카벤(carbene)' 계열 분자를 개발했다.
분자는 원자 조합을 조절해 원하는 특성을 설계하고 동일한 구조로 반복 합성할 수 있다는 장점이 있다. 엔비전은 이 같은 특성을 활용해 양자 칩의 제조 복잡성을 낮추겠다는 구상이다.
연구진이 개발한 분자는 전자의 스핀 상태에 따라 서로 다른 주파수의 빛을 방출한다. 이를 이용해 레이저로 개별 분자의 양자 상태를 초기화하고, 마이크로파로 제어한 뒤, 빛을 통해 상태를 읽어내는 데 성공했다. 엔비전은 단일 유기 분자에서 이 세 가지 과정을 모두 구현한 것은 처음이라고 설명했다.
실험에서 분자의 양자 상태는 동적 디커플링 기법을 적용했을 때 최대 2.2밀리초 동안 유지됐으며, 스핀 상태를 전환하는 데 걸리는 시간은 50나노초 미만이었다. 연구진은 양자 정보가 사라지기 전에 수만 차례의 상태 전환이 가능한 수준이라고 설명했다. 실험은 약 4.5K(영하 268.7도)의 극저온에서 진행됐다.
특히 분자 큐비트를 얇은 막 형태로 제작해 기존 광자 집적회로(PIC)에 증착할 수 있다는 점이 제조상의 장점이다. OLED 디스플레이에서 유기 발광 물질을 얇게 입히는 것과 유사한 방식을 활용할 수 있기 때문이다. 다만 실제 광자 반도체 칩에 분자를 통합한 상태에서도 동일한 양자 성능을 유지할 수 있는지는 아직 검증해야 한다.
엔비전은 큐비트를 하나의 칩에 밀집시키는 대신 광자를 통해 서로 연결하는 광자 기반 양자 컴퓨터를 개발할 계획이다. 이를 통해 칩 내부뿐 아니라 여러 칩 사이에서도 양자 정보를 전달하고, 큐비트 수가 늘어날 때 발생하는 제어 복잡성을 줄이겠다는 구상이다.
실제 칩 개발을 위해 미국 광자 반도체 기업 하이퍼라이트(HyperLight)와 전략적 협력도 발표했다. 하이퍼라이트의 박막 리튬나이오베이트(TFLN) 광자 집적회로에 엔비전의 분자 큐비트를 통합할 계획이다.
셀라 브로시 엔비전 CEO는 "우리는 전체 과정을 직접 수행하고 싶다"라며 "칩을 제조하고 분자를 증착한 뒤 그 위에서 오류 정정까지 구현할 것"이라고 말했다. 이어 "궁극적으로 판매하려는 제품은 데이터센터에 바로 설치할 수 있는 완성형 컴퓨터"라고 덧붙였다.
이 회사는 2026년 4분기 첫 통합 칩 시제품을 확보하고 연말까지 실제 광자 집적회로에서 성능을 시연한다는 목표다. 2030년까지 물리적 큐비트 1000개를 구현하고, 장기적으로 오류 정정이 가능한 논리적 큐비트 1000개 규모의 시스템을 개발한다는 계획도 제시했다.
엔비전은 원래 자기공명영상(MRI)의 영상 품질을 개선하는 기술을 개발하던 기업이다. 전자 스핀을 제어하는 기존 기술을 양자 컴퓨팅으로 발전시켰으며, 이번 연구를 통해 분자 기반 큐비트의 실제 반도체 칩 적용 가능성을 검증하는 단계에 들어섰다.
