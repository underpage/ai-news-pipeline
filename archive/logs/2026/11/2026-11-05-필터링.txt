오픈AI가 정지 이미지 중심이었던 챗GPT의 이미지 생성 기능을 움직이는 애니메이션 영역으로 확장했다. 이미지 생성 속도를 50% 높이고 편집 정밀도도 개선해 콘텐츠 제작에 활용할 수 있는 범위를 넓혔다.
오픈AI는 4일(현지시간) 공식 블로그를 통해 이미지 생성 모델 '이미지 2.6(Images 2.6)'을 공개하고, 챗GPT에서 애니메이션 GIF를 직접 만들고 편집할 수 있는 기능을 추가했다고 밝혔다.
이번부터 제품 명칭에는 기존 'GPT 이미지(GPT Image)' 대신 '이미지(Images)'를 사용한다. 다만 개발자용 API 모델에는 GPT 이미지라는 이름을 유지했다.
이번 업데이트의 핵심은 별도의 제작 도구 없이 자연어 명령만으로 움직이는 GIF를 만들 수 있다는 점이다. 사용자는 원하는 장면과 움직임을 설명하거나 기존 사진을 업로드해 GIF를 생성할 수 있다. 예를 들어 춤추는 고양이를 만들어 달라고 요청하면 움직이는 이미지가 생성된다. 간단한 스케치를 영상이나 게임에 활용할 수 있는 애니메이션 캐릭터로 바꾸는 것도 가능하다.
생성한 GIF는 재생 속도를 조절하거나 개별 프레임을 수정할 수 있다. 애니메이션을 구성하는 장면을 하나씩 확인하고 결과물을 공유하는 기능도 지원한다. 이를 통해 브랜드 마스코트나 소셜미디어용 밈, 광고용 애니메이션 등을 제작할 수 있다.
이미지 생성 성능도 개선됐다. 오픈AI에 따르면 이미지 2.6은 지난 9월 출시한 2.5 버전보다 이미지 생성 속도가 50% 빨라졌다. 여러 차례 수정 작업을 거쳐도 캐릭터의 외형과 제품 디자인, 브랜드 고유의 시각적 특징을 일관되게 유지하는 능력을 강화했다. 포스터와 제품 이미지 등 전문적인 시각 콘텐츠의 레이아웃 품질도 개선했다.
2.5 버전은 외부 성능 평가에서도 최상위권을 유지하고 있다. 아티피셜 애널리시스(Artificial Analysis)의 이미지 생성 평가에서 'GPT 이미지 2.5 선버스트'는 1223점으로 1위, 'GPT 이미지 2.5 플레어'는 1207점으로 2위를 기록했다. 이미지 편집 평가에서도 선버스트가 1199점으로 1위다.
이번에 공개한 2.6 모델은 아직 이 평가에 포함되지 않았다.

[FIELD] 보안
[BODY]
Cybersecurity researchers have disclosed details of an OpenAI Codex jailbreak bundle that's designed to modify an artificial intelligence (AI) agent's trusted instructions to insert advertisements for a third-party AI gateway.
The phenomenon has been codenamed prompt adware by Check Point Research.
Called Haiou (meaning Seagull in Chinese), the jailbreak modifies OpenAI Codex's configuration files to inject advertisements for the jailbreak author's website into subsequent agent responses.
"The advertised service is an opaque, OpenAI-compatible LLM gateway, a middleware between an application and an LLM provider," Check Point Research said in a technical report. "The likely business model is to use the freely distributed jailbreak bundle as an acquisition channel for the paid gateway service."
Adware is a type of software that displays unwanted advertisements, which can appear on users' computers or mobile devices, often in the form of pop-ups or banners. Prompt adware extends this sketchy behavior to AI agents by means of a jailbreak that defeats the model's safety training and content guardrails.
The idea is to persistently modify the agent's global instructions through natural language to influence future responses. This, in turn, causes common greetings or activation words like "Seagull," "hi," "hello," "hey," "yo," and "are you there?" to trigger an advertisement for "zz.aiapi2025[.]top."
Haiou attempts to jailbreak a model by using several prompt injection techniques, such as role-playing and reframing cybersecurity-related requests into a Capture The Flag (CTF) scenario. In addition, it installs security-focused skills devoted to penetration testing, cracking, and reverse engineering.
However, it doesn't stop there. The bundle also injects persistent ads into the global agent instruction file to promote the LLM gateway website. On GitHub, "haiou-codex" is advertised as a "local enhancement configuration package" that adds a "Chinese technical personality and security research workflow to Codex." As of writing, the repository has been forked 77 times and starred 403 times since it was made available on July 10, 2026.
It's worth noting that Codex is not officially available in mainland China, suggesting that the service is likely aimed at individuals or organizations wanting to try out Western AI coding assistants. Check Point researchers told The Hacker News that "we don't have strong evidence, but these resell of gateways are more phishy, like laundering stolen LLMs tokens for example."
What's more, the jailbreak has been bundled within Codex-X, an open-source Chinese visualization tool for configuring Codex through a graphical user interface.
"The behavior is introduced through natural-language instructions and configuration, rather than a traditional executable payload that users and security teams may more readily recognize as software behavior," Pedro Drimel Neto, malware analysis team leader at Check Point, said.
While serving an ad may seem relatively harmless in the larger scheme of things, the findings demonstrate how a bad actor could introduce undesirable behavior through third-party skills or configurations, leading to supply chain attacks.
"As AI agents become part of enterprise environments, the prompts, Skills and third-party components influencing their behavior become part of the trust chain too," Neto said.

A flaw in APT, the package manager for Debian and Ubuntu, allows an attacker who can modify package downloads to swap a checked package for their own.
The attacker's code then runs as root, according to advisories that Debian, Ubuntu, and APT's developers published on November 4. The attack needs APT to retry failed downloads, which it does by default from Debian 12 and Ubuntu 22.04 onward.

Ubuntu published new APT builds for four of its releases to its security archive at 14:25 UTC on November 4:
- Ubuntu 26.10: 3.3.3ubuntu0.1
- Ubuntu 26.04 LTS: 3.2.1ubuntu0.1
- Ubuntu 24.04 LTS: 2.8.4ubuntu0.1
- Ubuntu 22.04 LTS: 2.4.15ubuntu0.1
At 15:46 UTC, Ubuntu still marked all eight releases it tracks for the flaw, from 14.04 LTS to 26.10, as vulnerable.
The attacker can be anyone who can change the HTTP traffic between APT and the package server, including a malicious mirror or proxy, according to Ubuntu. The attack runs when the computer installs a package. The attacker uses HTTP redirects and ordinary temporary server errors to make APT retry the download, APT's developers say.
Max Justicz reported the flaw. None of the three advisory reports describe attacks exploiting the flaw or offer a workaround for systems that cannot update yet. They describe the attack over HTTP and do not say whether package sources reached over HTTPS are exposed.

Zyxel has patched a zero-day vulnerability in its GS1900 series network switches that hackers exploited to compromise nearly 1,000 devices worldwide and steal configuration files and credentials.
The vulnerability, tracked as CVE-2026-107441, is an out-of-bounds write flaw in the switches' web management interface that allows an unauthenticated attacker with network access to execute operating system commands using specially crafted HTTP requests.
The flaw affects ten GS1900 switch models, and Zyxel released security updates on October 22 and published a security advisory on November 3.
However, the vulnerability was initially mistaken for an older flaw that Zyxel had already patched months before the attacks began.
Attacks linked to zero-day flaw
On June 16, 2026, Zyxel released security updates addressing CVE-2026-7273, a pre-authentication buffer overflow vulnerability affecting the same GS1900 switches.
Starting around August 17, cybersecurity company GreyNoise observed a suspected Chinese-speaking threat actor tracked as Kapibala exploiting Zyxel switches, reporting that the attackers compromised 996 devices across 48 countries.
The threat actors exploited the flaw to execute commands remotely before downloading a script that collected device configurations, hashed root credentials, and network information.
GreyNoise linked Kapibala to the Red Heron hacking campaign, which Acronis previously reported was exploiting a critical vulnerability in the self-hosted Git service Gitea.
When GreyNoise disclosed the campaign on September 21, it attributed the exploitation to CVE-2026-7273, the vulnerability Zyxel had patched in June.
That same day, CISA added CVE-2026-7273 to its Known Exploited Vulnerabilities catalog, requiring federal agencies to address the flaw.
However, researchers at firmware security company Binarly discovered that the exploit used in the attacks actually targeted a separate, previously unknown vulnerability that remained unpatched.
While investigating Red Heron infrastructure linked to the JITTERLY backdoor and SIXZUT rootkit, Binarly researchers found an exposed archive containing an obfuscated Python exploit targeting Zyxel GS1900 switches.
After analyzing the exploit, the researchers found that it specifically checked for firmware versions patched for CVE-2026-7273, indicating the exploit had been developed or updated to target those versions.
Binarly confirmed on September 28 that the exploit remained effective against all ten firmware releases patched for CVE-2026-7273.
The researchers determined that the earlier security update added checks to prevent a buffer overflow, but attackers could bypass them by corrupting a parameter counter before it was validated.
This allowed the exploit to overwrite memory and execute commands without authentication, even on switches running the earlier security updates.
Binarly reported its findings to Zyxel on September 29, and the vendor confirmed the new vulnerability on October 11, assigning it CVE-2026-107441.
Zyxel classified it as a separate flaw because the exploit also abused missing validation of HTTP parameter lengths.
On October 22, Zyxel released new firmware updates that limit parameter sizes and validate the parameter count before copying data into memory, preventing the exploitation technique.
While the recovered exploit specifically targeted firmware patched for CVE-2026-7273, it remains unclear whether it was deliberately developed to bypass those updates or exploited a related vulnerability that the earlier patches failed to address.
Administrators of affected Zyxel GS1900 switches are advised to install the latest firmware updates to protect against CVE-2026-107441.
