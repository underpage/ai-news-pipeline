[REASON] AI 개발 도구 마켓플레이스 침해를 통한 악성 확장 유포
[FIELD] 보안
[BODY]
Cursor confirmed it suffered a security breach that let hackers distribute a malicious Claude Code extension through its marketplace after stealing credentials from AI infrastructure provider Fireworks AI.
The breach also let attackers access internal systems and steal customer data, including historical AI coding-agent traces containing unredacted credentials that were later used to compromise additional services.
The breach was disclosed in a new incident report published Friday, which explains how attackers distributed malicious versions of Anthropic's Claude Code extension through Cursor's marketplace on October 29.
The attack exposed up to 5,000 developers to malware that installed persistent SSH backdoors.
Cursor is an AI-powered code editor built on Microsoft's open-source Visual Studio Code (VS Code), allowing developers to write, modify, and debug software using AI assistants.
According to Cursor, the attack began when hackers obtained an access key stored on Fireworks AI, a third-party provider used for AI model training and inference.
The attackers used the exposed key to copy data from a read-only storage bucket Cursor used to share information with Fireworks.
This bucket contained historical AI coding-agent traces, mostly from 2025, collected from users who had not enabled Privacy Mode and whose data could be used for model training. Some of these traces contained unredacted API credentials, allowing the attackers to access additional Cursor systems.
Cursor says fewer than 0.05% of users had coding-agent traces exposed, while fewer than 0.01% of customers had API credentials compromised.
Using the exposed credentials, the hackers stole data from several of Cursor's software-as-a-service (SaaS) tools, including:
- Archived, non-production Cursor source code repositories, some containing business contact information.
- Limited customer support information and email conversations.
- Product usage metrics and customer contact details.
- Summaries of some AI coding-agent conversations.
- Credentials that customers had previously shared with Cursor's support team.
Cursor says its monitoring systems detected the unauthorized activity, leading the company to revoke the Fireworks access key, rotate exposed credentials, and investigate additional unauthorized access.
As the investigation progressed, Cursor temporarily turned off some internal and product services as a precaution.
However, the attackers had already obtained a credential that allowed them to distribute extensions through Cursor's marketplace.
On October 29, the hackers used that credential to publish malicious copies of Anthropic's Claude Code extension on Cursor's VS Code extension marketplace.
"On October 29, using a stolen credential from the exposed data from our internal system, the attacker placed malicious, unauthorized copies of Anthropic's Claude Code extension directly on the cache used to serve the Cursor VS Code extension marketplace," Cursor explained.
The attack did not compromise Anthropic's legitimate extension or Open VSX, the extension marketplace Cursor uses.
The malicious extensions, versions 2.1.312 and 2.1.313, were available for approximately 11 hours before Cursor removed them.
As BleepingComputer previously reported, the attackers modified the legitimate Claude Code extension to execute malicious JavaScript that attempted to install persistent SSH backdoors on developers' computers.
The malware collected system information, installed an attacker-controlled SSH key, attempted to enable SSH access, and configured persistence mechanisms to maintain remote access.
However, security researchers found coding errors that likely prevented the backdoor from working on many Windows and macOS systems where SSH was not already enabled.
Cursor estimates that up to 5,000 users who requested affected extension versions during the exposure window may have received the malicious builds.

아마존의 스마트 보안기기 자회사 링(Ring)은 자율 이동형 보안기기 사업인 '링 로보틱스(Ring Robotics)'를 발표하고, 가정용 비행 보안카메라 '링 드론 캠(Ring Drone Cam)'과 사업장용 자율 순찰로봇 '링 로버 캠(Ring Rover Cam)'을 공개했다.
가정 내부를 비행하는 드론과 사업장을 이동하는 바퀴형 로봇을 통해 기존 고정형 보안카메라의 감시 범위를 확장하고, AI 기반 자율 순찰과 현장 확인 기능을 결합한 새로운 보안 서비스 시장을 목표로 한다.

AI가 실내 지도 생성하고 순찰 경로 결정, 이상 신호에 자동 대응
링 로보틱스의 핵심은 기존 보안카메라가 설치된 위치에서 영상을 수집하는 데 그치지 않고, AI가 공간을 이동하며 필요한 장소를 확인하도록 설계됐다는 점이다. AI 파일럿은 기기의 카메라와 센서로 수집한 정보를 분석해 실내 평면도를 생성한다. 드론은 사용자가 기기를 들고 공간을 이동하면서 초기 지도를 만들 수 있으며, 로버는 스스로 공간을 탐색해 지도를 구성한다.
이 과정에서 AI는 출입문과 창문, 계산대, 긴 복도 등 보안상 확인이 필요한 장소를 식별하고 순찰 지점으로 제안한다. 사용자는 자신의 보안 요구에 따라 추가 지점을 지정할 수 있다.
순찰이 시작되면 AI 파일럿은 생성된 지도를 바탕으로 설정된 목적지까지 이동 경로를 계산한다. 이동 중 가구와 진열대 등 장애물이 나타나면 이를 감지하고 실시간으로 회피한다. 또한 기존 링 카메라나 센서, 경보장치에서 이상 신호가 발생하면 해당 위치를 확인하도록 드론이나 로봇을 자동으로 이동시킬 수 있다.
이는 영상 감시와 이상 상황 감지, 현장 확인을 하나의 시스템으로 연결하는 방식이다.

링 로버 캠은 미국에서 2026년 12월 16일부터 배송을 시작할 예정이며, 가격은 999.99달러다. 링 드론 캠은 2027년 1월 27일 미국 고객 대상 배송을 시작할 계획이며, 가격은 249.99달러로 책정됐다.

[TITLE] C++26, 표준화 사상 첫 부결…연내 확정 불투명

[FIELD] 신기술
[BODY]
C++ 프로그래밍 언어의 차기 표준인 'C++26'이 국제표준화기구(ISO) 승인 단계에서 사상 처음으로 부결됐다.
프로그램 실행 중 오류를 감지하는 '계약(Contracts)' 기능을 둘러싸고 언어 창시자와 표준화위원회 의견이 충돌하면서다. 이번 부결로 연내 표준 확정이 불투명해졌으며, 정적 리플렉션 등 다른 신기능 도입도 지연될 가능성이 커졌다.
15일 더레지스터 등 외신에 따르면 C++26 국제표준초안(DIS)은 지난 10월 ISO 회원국 표준기구 투표에서 찬성 13표, 반대 9표, 기권 12표를 기록하며 승인 요건을 충족하지 못했다.
DIS는 각국 표준기구가 표준의 기술적 내용을 공식 승인하는 절차로, 최종 확정 직전 단계에 해당한다. C++ 표준화위원회(WG21) 소속 안드레아스 페르티히 위원은 C++ 표준안이 이 단계에서 부결된 것은 처음이라고 밝혔다.
이번 부결은 계약 기능에 대한 이견으로 발생했다. 계약은 개발자가 함수 실행 전후에 충족해야 할 조건을 코드에 명시하고 프로그램 실행 중 이를 검사하도록 지원하는 기능이다. 잘못된 입력값이나 예상과 다른 실행 결과를 감지해 오류와 보안 취약점으로 이어질 수 있는 문제를 줄이는 것이 목적이다.
이 기능은 C++20에 포함될 예정이었으나 설계 문제로 제외됐다. 이후 수년간 보완 작업을 거쳐 C++26 표준안에 다시 포함됐다. 지난 3월 WG21 전체회의에서도 계약 기능이 포함된 표준안이 찬성 114표, 반대 12표, 기권 3표로 통과됐다.
하지만 C++ 창시자인 비야네 스트롭스트룹 콜롬비아대학 교수는 설계가 지나치게 복잡하고 충분히 검증되지 않았다며 반대했다.
그는 지난 8월 공동 작성한 기술 문서에서 현재 계약 기능 제안(P2900)이 C++의 복잡성과 코드 규모를 늘리고 언어의 본질을 바꿀 수 있다고 비판했다. 계약 기능 자체보다는 현행 설계에 문제가 있으며 더 단순한 형태로 구현해야 한다는 주장이다.
도입 찬성 측은 수년간 논의하고 여러 차례 표결을 거친 기능을 최종 승인 단계에서 뒤집는 것이 표준화 절차 신뢰를 훼손한다고 반발했다.
허브 서터 전 WG21 의장도 지난달 31일 발표한 기술 문서에서 이번 부결의 핵심 배경으로 언어 창시자와 위원회 다수의 의견 충돌을 지목했다. 위원회가 계약 기능 도입에 폭넓게 합의했지만 스트롭스트룹이 설계상 결함을 이유로 반대했고, 일부 국가 표준기구도 이에 동조했다는 분석이다.
WG21은 오는 16일부터 21일까지 브라질 부지우스에서 회의를 열고 대응 방안을 논의할 예정이다. 계약 기능을 표준안에서 제외하거나 별도 기술명세서로 분리하는 방안, 현행 설계를 일부 수정해 재투표하는 방안 등이 거론된다.
어떤 방안을 선택하더라도 추가적인 합의와 승인 절차가 필요해 표준화 일정이 지연될 가능성이 있다. 표준 확정이 내년으로 넘어갈 경우 현재 통용되는 C++26 대신 'C++27'이라는 명칭이 사용될 수도 있다.

Runway's open-source Praxis-1 turns video AI into a robot controller
Key Points
- Runway has released its robot model Praxis-1 with open weights and source code under the Apache 2.0 license.
- Trained on videos and robot data, the model processes camera images, text instructions, and position data to calculate matching robot movements.
- Praxis-1 can be adapted to new robot systems through additional training, according to Runway. The model does occasionally confuse similar-looking objects, though, and it can't yet reliably plan complex action sequences on its own.
AI company Runway has released its robot model Praxis-1 with open weights and source code. The model uses what it learned from video to control robots and shows promising results in the company's own tests.
Runway has released Praxis-1, its AI model for controlling robots. The company first introduced Praxis-1 in late September but initially gave access only to select partners. Alongside the release, Runway published a detailed research report with new performance tests.
Runway's model weights and source code are available under the Apache 2.0 license, which allows commercial use.
Praxis-1 takes in camera images, text instructions, and information about a robot's position. From those inputs, it predicts how the environment will change and calculates the right robot movements. As new camera frames come in, the model continuously adjusts its control.
Praxis-1 builds on video training to control robots
Praxis-1 builds on a video model that learned how objects move and interact from ordinary footage. Runway then fine-tuned it with videos of human actions and robot data. This approach could reduce the need for expensive robot-specific datasets, which have traditionally been collected just to train these kinds of systems.
Runway is best known for generative video models like Gen-4.5. With Praxis-1, the company is bringing its video research into robotics. Runway calls Praxis-1 a World Action Model that predicts how a scene will change and derives matching robot movements from those predictions. Since September, robotics companies Standard Bots, Noble Machines, and Ultra have been testing Praxis-1 on different systems, including a humanoid robot, an industrial robot arm, and a dual-arm warehouse robot.
Praxis-1 leads among World Action Models
Praxis-1 still needs some specialized robot data. To adapt it to a Franka robot arm, Runway used about 277 hours of recordings from the public DROID research dataset, according to its research report. Those recordings show robots grasping and moving objects, for example. For a dual-arm robot, the company used between 1,400 and 2,600 hours of training material. Runway had already used DROID data and data from other robot systems during earlier training stages. Whether the approach actually needs less robot data overall than comparable models without general video pretraining is still an open question.
On Nvidia's RoboLab-120 leaderboard, Praxis-1 scores a 46.2 percent success rate. The benchmark tests how reliably robot models can sort, grasp, or stack objects across 120 tasks in simulation. FLUX 3 Action, also built as a World Action Model, scores 42.9 percent under the same test conditions. That puts Praxis-1 at the top of the World Action Model category. In the overall leaderboard, it ranks fifth behind two AI agents and two robot models with different architectures. Runway ran all the tests itself, and the results haven't been independently verified yet.
After fine-tuning on DROID data, Runway tested the model on a real Franka robot arm. Both models had to complete the same ten tasks, like placing a banana on a plate or closing a drawer. With ten attempts per task, Praxis-1 succeeded 88 times, while FLUX 3 Action managed 80.
Runway also tested how well Praxis-1 transfers to a robot type it had never seen before, using data from a mobile robot platform with a gripper arm that Google had previously used to develop RT-1.

- 반복되는 데이터베이스 연동 패턴은 유사한 접근 제어 오류를 여러 앱에서 찾기 쉽게 함. 실제 고객이나 업무 데이터를 다루기 전 전문가의 접근 권한 검토가 필요함
Lovable의 개발 편의성과 보안 책임
- Lovable은 Anton Osika와 Fabian Hedin이 2023년 스톡홀름에서 설립한 스웨덴 AI 스타트업으로, 자연어 설명을 웹 애플리케이션으로 변환함
  - 프로그래밍 경험이 거의 없거나 없는 사람도 사용할 수 있도록 설계됨
  - 2023년 공개된 Osika의 오픈소스 프로젝트 GPT Engineer에서 출발해 GPT Engineer App으로 발전했으며, 2024년 말 Lovable로 이름을 바꾸고 그해 11월 공개 출시함
- 정적 웹사이트부터 사용자 관리와 데이터베이스 연결을 갖춘 애플리케이션까지 만들 수 있지만, 기밀 정보를 처리하려면 무단 접근 방지 여부가 중요함
- Lovable은 바이브 코딩 소개, 비개발자 창업자 대상 글, 창업자 안내, 개발 안내에서 기술 지식 없이 프로젝트를 만들 수 있음을 강조함
  - 플랫폼이 보안까지 책임진다는 인상을 줄 수 있지만, 이용약관은 애플리케이션과 데이터 처리 책임을 고객에게 부여함
  - 간편한 올인원 서비스라는 약속과 고객이 실제로 맡아야 하는 책임 사이에 간극이 있음
조사 질문과 분석 방법
- Crissy Field는 Handelsblatt와 협력해 로그인 없이 민감 데이터에 접근할 수 있는지 조사함
  - 웹사이트를 처음 열 때 전송되는 데이터와, 같은 API 키로 추가 읽기 전용 요청을 보내 확인한 데이터를 구분함
- 분석 대상은 데이터베이스 서비스 Supabase 연동 앱으로 한정함
  - 연동 구조를 비교적 쉽게 분석할 수 있고, 조사팀은 Lovable 프로젝트에서 가장 널리 쓰이는 데이터베이스 서비스라고 판단함
  - 2025년 말 도입된 Lovable 자체 데이터베이스 기능은 사용이 상대적으로 적으며, 비슷한 설정 오류가 있을 수 있지만 이번에는 조사하지 않음
- Common Crawl 데이터셋을 활용해 2025년 12월부터 2026년 9월까지 Lovable 프로젝트 159,041개를 식별하고 분석함
  - 이 중 34,545개가 Supabase를 사용함
  - 24,664개 사이트는 로그인이나 다른 상호작용 없이 초기 로딩만으로 Supabase 레코드를 전송함
  - 공개 표시용 데이터일 수 있으므로, 초기 로딩 때 레코드를 전송한다는 사실 자체는 보안 문제가 아님
- 추가 읽기 전용 요청으로 더 많은 데이터베이스 콘텐츠를 조회했으며, 상세 조사 대상의 30%인 7,403개 사이트의 10,560개 테이블에서 이메일 주소가 포함된 레코드를 확인함

- 이메일 주소는 개인정보가 포함된 레코드를 찾는 단서지만, 공개 연락처나 테스트 데이터일 수도 있음
  - 반대로 이메일 주소가 없는 개인정보 레코드는 이 방식으로 놓칠 수 있음
  - 두 효과가 어느 정도 상쇄되는지는 확인하지 못함
- 
30%를 확정된 데이터 유출률로 해석하면 안 됨
  - 이 비율은 더 자세히 조사한 24,664개 사이트에만 적용됨
  - Common Crawl 기반 표본은 전체 Lovable 애플리케이션을 대표하지 않음
  - 데이터셋 전체가 아니라 일부만 조회하고 다운로드했으므로, 사례별 수치는 실제 확보한 레코드 수이며 노출된 전체 데이터는 더 많을 수 있음
  - 추가 접근을 쉽게 만들 수 있어 접근 방법의 세부 사항은 공개하지 않음
실제로 확인한 민감 데이터 노출
- 독일의 한 라이프스타일 포럼에서 8만 개 이상의 프로필과 20만 건 이상의 채팅 메시지에 접근할 수 있었음
  - 프로필에는 이름 전체, 이메일 주소, 생년월일, 성별 정보가 포함됨
- 여러 행사 주최사와 음식점에서 로그인 없이 티켓과 음식 판매 관련 레코드 수만 건에 접근할 수 있었음

- 한 부동산 관리 회사에서는 내부 이메일의 AI 생성 요약이 노출됐으며, 세입자와 부동산 소유주, 사업 파트너에 관한 민감 정보가 담겨 있었음
- 한 서비스 제공업체에서는 신분증 정보가 포함된 레코드 1,000건 이상이 노출됨
  - 여권 번호, 만료일, 국적 등이 포함됐으며, 이런 정보는 신원 도용에 악용될 수 있음
- 그 밖에도 계약서, 청구서, 개인 사진 앨범, 내부 WhatsApp 대화 등 수만 건의 콘텐츠에 접근할 수 있었음
- 다수의 뉴스레터 구독 정보, 대기자 명단, 연락 및 지원 문의도 노출됨
  - 한 사례에서는 제공업체가 고객에게 보낸 이메일 28만 건에 접근할 수 있었음
- 노출된 정보는 내용에 따라 피싱, 티켓 사기, 신원 도용에 악용될 수 있지만, 실제 악용 여부는 확인하지 못함
- Handelsblatt는 조사 결과를 Lovable에 전달함

- 접근 제어 오류는 사람이 작성한 앱과 AI로 만든 앱 모두에서 발생할 수 있으며, 이번 조사에서는 여러 Lovable 앱이 고도로 민감한 데이터까지 보호하지 못했음
- Lovable의 데이터베이스 연동에는 반복되는 패턴이 있어, 공격자가 여러 앱의 유사한 설정 오류를 찾기 쉬움
  - 한 앱에 통하는 접근 방식이 다른 앱에도 적은 추가 노력으로 통할 수 있음
  - 기술 배경이 없는 사용자는 이런 결함을 발견하고 예방하기 더 어려움
- 개발 플랫폼이 사용하기 쉽더라도, 기밀 데이터를 다루기 전 전문가의 접근 권한 검토가 필요함

[TITLE] 아마존, 전 세계 상품 정보 통합 추진…AI 쇼핑 주도권 지킨다
[LINK] https://www.aitimes.com/news/articleView.html?idxno=217412
[PUBLISHED] 2026-11-14 19:19 KST
[SOURCE] AI타임스
[TOPIC] 에이전트, 모델
[SCORE] 6
[REASON] 쇼핑 에이전트 유치를 위한 글로벌 상품 데이터 그래프 구축
[FIELD] AI 에이전트
[BODY]
아마존이 자사에서 판매하지 않는 제품까지 전 세계 상품 정보를 모으는 방안을 검토하고 있다. 소비자가 제품을 비교하기 위해 다른 사이트로 이동하는 일을 줄이고, 구매를 대신하는 외부 AI 에이전트도 아마존을 찾도록 하려는 구상이다.
로이터는 13일(현지시간) 내부 문서와 관계자들을 인용해 아마존이 ‘월드 프로덕트 그래프(World Product Graph)’라는 프로젝트를 추진하고 있다고 보도했다.
브랜드에서 제공받는 정보와 다른 유통 사이트에서 수집한 데이터를 결합해 상품 간 차이와 관계를 파악하는 것이 목표다. 이용자가 최신 모델을 구별하거나 자신에게 맞는 제품을 고를 때 필요한 정보를 아마존 안에서 찾도록 한다는 것이다.
상품 정보를 수집하기 위해 다른 업체의 웹사이트를 자동으로 탐색하는 방식도 구상에 포함됐다. 다른 업체의 웹사이트에서 어떤 방식으로 정보를 수집할지, 이 과정에서 각 업체의 허가를 받아야 하는지는 확인되지 않았다.
자체 AI 쇼핑 도우미의 정확도를 높이고 운영 비용을 줄이려는 목적도 담겼다. 내부 문서는 기존 ‘루퍼스’의 답변에 오류와 누락이 있으며, 상품 정보를 보강하면 저렴한 모델을 효율적으로 사용할 수 있다고 설명했다.
이에 대해 아마존은 현재 AI 쇼핑 도우미인 ‘알렉사 포 쇼핑’의 답변 정확도가 자체 집계 기준 약 97%라고 설명했다. 내부 문서에서 지적한 오류 문제가 현재 서비스 수준을 그대로 보여주는 것은 아니라는 취지다. 알렉사 포 쇼핑은 기존 ‘루퍼스’의 이름을 지난 5월 바꾼 서비스다.
외부 AI 에이전트가 상품을 비교해 다른 쇼핑몰에서 구매하도록 안내하면, 소비자가 아마존을 방문하거나 광고를 볼 기회가 줄어들 수 있다. 관계자들은 아마존이 폭넓은 상품 정보를 갖추면 외부 AI 에이전트도 제품을 찾고 비교할 때 아마존을 이용하도록 유도해 광고 사업을 지킬 수 있다고 설명했다.
아마존은 이미 외부 쇼핑몰 상품을 보여주는 ‘숍 다이렉트(Shop Direct)’와 구매를 대신하는 ‘바이 포 미(Buy for Me)’를 운영하고 있다. 이용자는 판매자 사이트로 이동해 직접 구매하거나, 일부 상품은 아마존의 AI 구매 기능을 통해 주문할 수 있다.
이번 구상은 외부 상품을 연결하는 기존 서비스에 비교·추천에 필요한 정보를 보강하려는 움직임으로 해석된다. AI 쇼핑 경쟁에서 상품 판매뿐 아니라 소비자의 선택과 구매를 연결하는 역할까지 확보하려는 전략이다.
내부 문서에는 내년 10월1일 출시를 목표로 제시했지만, 실행 여부와 일정은 확정되지 않았다. 아마존은 오래된 검토 문서로 현재 계획과 다를 수 있다고 밝혔다.

[TITLE] 구글 딥마인드, AI 강수 탐지 정확도 30% 이상 향상…전 세계 기상·위성 데이터셋 전면 공개
[LINK] https://www.aitimes.kr/news/articleView.html?idxno=42738
[PUBLISHED] 2026-11-15 16:41 KST
[SOURCE] 인공지능신문
[TOPIC] 개발
[SCORE] 6
[REASON] 정밀 강수 탐지 모델 및 위성 데이터셋 공개
[FIELD] AI 모델
[BODY]
위성영상 통합한 ‘새트위브’와 AI 강수 데이터 ‘파르디그’ 공개…홍수·가뭄·산불·재생에너지 예측 연구 지원
구글 딥마인드(Google DeepMind)가 인공지능(AI)을 활용해 전 세계 강수량을 정밀하게 분석하는 기술과 지구 관측 위성영상을 통합한 데이터셋을 공개했다. 기존 글로벌 강수 관측자료보다 약한 비와 보통 강수의 탐지 성능을 30% 이상 높였으며, 이를 연구자와 개발자가 활용할 수 있도록 개방해 AI 기반 기상·기후 예측 기술의 확산에 나섰다.
구글 딥마인드는 지난 13일(현지시간) AI 기반 글로벌 강수 데이터셋 ‘파르디그(PARDIG-다운)’와 정지궤도 위성영상 통합 데이터셋 ‘새트위브(SatWeave-다운)’를 공개한다고 발표했다. 두 데이터셋은 구글이 앞서 공개한 차세대 AI 기상예측 모델 ‘웨더넥스트 3(WeatherNext 3-보기)’의 성능 향상에 활용된 핵심 데이터 기반이다.
새트위브는 지구 전역의 구름과 폭풍 발달 상황을 위성영상으로 제공하고, 파르디그는 AI를 통해 강수 분포를 추정해 기상예측 모델 학습에 활용됐다. 구글은 두 데이터셋의 과거 관측자료와 최신 데이터 공급 체계를 함께 개방해 기상예측뿐 아니라 수문학, 기후변화, 자연재해 분석 등 다양한 분야의 연구개발을 지원할 계획이다.
AI로 전 세계 강수 분포 복원, 15분 간격·약 10㎞ 해상도 제공
파르디그는 ‘강수 AI 재분석: 고밀도 추론 GPM(Precipitation AI Reanalysis: Densely Inferred GPM)’의 약자로, 위성 관측자료와 대기 정보를 활용해 전 세계 강수 분포를 추정하는 AI 기반 데이터셋이다. 관련 연구는 지난 10일(현지시간) 'PARDIG: 위성 관측 자료가 부족한 상황에서 얻은 전 세계 강수량 추정치(PARDIG: Global Precipitation Estimates Learned from Sparse Satellite Observations-다운)'란 제목으로 발표됐다.
기존 강수 관측은 지상 기상레이더와 강우계에 크게 의존해 왔다. 그러나 관측 장비가 충분하지 않은 지역에서는 강수량을 정밀하게 파악하기 어렵고, 국가별 관측망의 밀도 차이로 인해 전 세계적으로 일관된 자료를 확보하는 데 한계가 있었다.
구글은 이러한 문제를 해결하기 위해 미국 항공우주국(NASA)의 전 지구 강수 관측 임무(GPM) 핵심 위성에서 수집한 우주 기반 레이더 관측자료를 AI에 학습시켰다. 여기에 새트위브의 위성영상과 유럽중기예보센터(ECMWF)의 대기장 자료를 입력해 관측이 드문 지역까지 강수 분포를 추정하도록 했다.
파르디그는 약 10㎞ 공간 해상도로 전 세계 강수 분포를 표현하며, 15분 간격의 강수 데이터를 제공한다. 최신 자료는 평균 약 5시간의 지연을 거쳐 갱신된다. 이는 AI가 위성 관측과 대기 정보를 결합해 지상 관측망이 부족한 지역의 강수 분포까지 추정하도록 설계됐다는 점에서 의미가 있다.
NASA 강수 자료보다 탐지 성능 30% 이상 향상, 극한 강수 분석에도 강점
구글 딥마인드는 파르디그의 성능을 검증하기 위해 미국과 유럽, 일본의 광역 기상레이더 관측망 3곳과 전 세계 3만6000여 개 기상관측소의 자료를 활용했다. 검증 결과 파르디그는 분석 대상의 모든 강수 강도 구간에서 주요 글로벌 강수 추정 데이터셋보다 높은 성능을 기록했다.
특히 NASA의 ‘아이머지 파이널(IMERG-Final)’과 비교했을 때 약한 비와 보통 강수에 대한 시간별 탐지 성능이 30% 이상 향상됐다. 이 수치는 전체 강수량 예측 오차가 30% 감소했다는 의미가 아니라, 시간별 강수 탐지 성능을 나타내는 지표에서 확인된 개선 결과다.
연구팀은 강한 비와 극한 강수 현상을 포착하는 데도 파르디그가 높은 성능을 보였다고 설명했다. 극한 강수는 짧은 시간에 급격하게 발달할 수 있어 기존 글로벌 관측자료에서 정확하게 탐지하기 어려운 현상 중 하나다.
구글은 2025년 7월 미국 텍사스 힐컨트리 지역에서 발생한 돌발홍수 당시의 강수 분포를 사례로 제시했다. 미국 해양대기청(NOAA)의 지상 레이더 자료와 파르디그, NASA의 아이머지 자료를 비교해 집중호우의 공간적 분포를 분석했다.
정지궤도 위성영상 통합, 지구 전체를 1시간 간격으로 관측
함께 공개된 새트위브는 서로 다른 정지궤도 기상위성에서 수집한 영상을 하나의 글로벌 관측자료로 통합하는 데이터셋이다.
지구를 관측하는 정지궤도 위성들은 담당 지역과 센서 특성, 지도 투영 방식, 영상 파일 형식, 촬영 주기가 서로 다르다. 이 때문에 각 위성의 자료를 하나의 일관된 지구 관측영상으로 결합하는 과정에는 상당한 기술적 어려움이 따른다.
기존 글로벌 위성영상 합성자료는 이러한 차이로 인해 일부 관측 채널만 제공하거나 수 시간 간격으로 갱신되는 경우가 많았다. 새트위브는 미국의 고스(GOES), 유럽의 메테오샛(Meteosat), 일본의 히마와리(Himawari) 등 주요 정지궤도 기상위성의 관측자료를 통합한다.
이를 통해 가시광선과 수증기, 적외선 등 17개 관측 채널을 포함하는 글로벌 위성영상 데이터를 구성한다. 특히 자료를 1시간 간격으로 갱신해 구름의 이동과 폭풍의 발달 등 빠르게 변화하는 기상 현상을 지속적으로 관찰할 수 있도록 했다.
구글에 따르면 새트위브는 웨더넥스트 3가 새로운 글로벌 예측을 매시간 생성할 수 있도록 지원한다. 이는 6시간 간격으로 갱신되는 분석자료를 초기 입력으로 사용하는 기상예측 방식과 차별화되는 부분이다. 구글은 10년 이상 축적된 새트위브의 과거 자료와 최신 데이터 공급 체계도 함께 공개(보기)했다.
1999~2026년 강수 데이터 개방, 홍수·가뭄·산불 연구로 확장
이번 발표에서 주목할 부분은 구글이 AI 기상예측 모델 자체를 넘어 모델 개발에 활용된 기반 데이터를 외부에 공개했다는 점이다. 파르디그는 1999년부터 2026년까지의 과거 강수 자료를 제공한다. 새트위브 역시 10년 이상의 위성영상 기록을 포함한다.
두 데이터셋의 과거 자료와 최신 데이터는 구글 클라우드 스토리지(Google Cloud Storage)를 통해 이용할 수 있으며, 파르디그의 과거 자료 목록은 구글 어스 엔진(Google Earth Engine-보기)에서도 제공된다. 연구자들은 이를 활용해 자체 기상예측 모델을 개발하거나 기존 예측 시스템의 성능을 검증할 수 있다.
구글은 특히 지상 기상레이더가 충분하지 않은 지역에서 강수 분석 기술의 활용 가능성이 클 것으로 기대하고 있다. 강수 관측자료는 홍수와 산사태, 가뭄 분석뿐 아니라 농업용수 관리와 수자원 계획에도 중요한 입력정보다.
AI 기상예측 경쟁, 모델 성능 넘어 관측 데이터 개방으로 확대
이번 발표는 AI 기반 기상예측 기술의 경쟁이 예측 모델의 성능뿐 아니라 관측자료의 품질과 접근성으로 확대되고 있음을 보여준다.
AI 기상예측 모델은 학습에 사용되는 데이터의 범위와 정확도, 최신성에 따라 성능이 달라질 수 있다. 특히 전 세계의 구름과 강수 변화를 빠르게 파악하려면 위성 관측자료를 일관된 형태로 통합하고, 관측이 부족한 지역의 정보를 보완하는 기술이 중요하다.
구글은 새트위브를 통해 글로벌 위성영상의 시간적 연속성을 높이고, 파르디그를 통해 강수 관측자료의 공간적 공백을 줄이는 접근 방식을 제시했다. 두 데이터셋은 웨더넥스트 3의 기상예측 성능을 뒷받침하는 동시에 다른 연구기관과 개발자가 자체 모델을 구축하는 데 활용할 수 있는 기반 자료라는 점에서 의미가 있다.
특히 기상 관측망이 충분하지 않은 지역에서도 AI 기반 강수 분석을 수행할 수 있는 환경이 확대된다면, 지역 간 기상정보 격차를 줄이는 데 기여할 가능성이 있다.
구글 딥마인드는 이번 데이터셋 공개를 통해 연구자들이 기상과 수문, 기후 분야의 새로운 응용 기술을 개발하고, 지구 관측정보를 실제 사회·산업 문제 해결에 연결할 수 있기를 기대한다고 밝혔다.
한편, 이번 연구개발은 구글 딥마인드와 구글 리서치(Google Research)가 주도하고 구글 클라우드(Google Cloud), 구글 지오(Google Geo)가 협력해 수행했다.
