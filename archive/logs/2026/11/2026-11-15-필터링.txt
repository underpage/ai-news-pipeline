[REASON] AI 개발 도구 마켓플레이스 침해를 통한 악성 확장 유포
[FIELD] 보안
[BODY]
Cursor confirmed it suffered a security breach that let hackers distribute a malicious Claude Code extension through its marketplace after stealing credentials from AI infrastructure provider Fireworks AI.
The breach also let attackers access internal systems and steal customer data, including historical AI coding-agent traces containing unredacted credentials that were later used to compromise additional services.
The breach was disclosed in a new incident report published Friday, which explains how attackers distributed malicious versions of Anthropic's Claude Code extension through Cursor's marketplace on October 29.
The attack exposed up to 5,000 developers to malware that installed persistent SSH backdoors.
Cursor is an AI-powered code editor built on Microsoft's open-source Visual Studio Code (VS Code), allowing developers to write, modify, and debug software using AI assistants.
According to Cursor, the attack began when hackers obtained an access key stored on Fireworks AI, a third-party provider used for AI model training and inference.
The attackers used the exposed key to copy data from a read-only storage bucket Cursor used to share information with Fireworks.
This bucket contained historical AI coding-agent traces, mostly from 2025, collected from users who had not enabled Privacy Mode and whose data could be used for model training. Some of these traces contained unredacted API credentials, allowing the attackers to access additional Cursor systems.
Cursor says fewer than 0.05% of users had coding-agent traces exposed, while fewer than 0.01% of customers had API credentials compromised.
Using the exposed credentials, the hackers stole data from several of Cursor's software-as-a-service (SaaS) tools, including:
- Archived, non-production Cursor source code repositories, some containing business contact information.
- Limited customer support information and email conversations.
- Product usage metrics and customer contact details.
- Summaries of some AI coding-agent conversations.
- Credentials that customers had previously shared with Cursor's support team.
Cursor says its monitoring systems detected the unauthorized activity, leading the company to revoke the Fireworks access key, rotate exposed credentials, and investigate additional unauthorized access.
As the investigation progressed, Cursor temporarily turned off some internal and product services as a precaution.
However, the attackers had already obtained a credential that allowed them to distribute extensions through Cursor's marketplace.
On October 29, the hackers used that credential to publish malicious copies of Anthropic's Claude Code extension on Cursor's VS Code extension marketplace.
"On October 29, using a stolen credential from the exposed data from our internal system, the attacker placed malicious, unauthorized copies of Anthropic's Claude Code extension directly on the cache used to serve the Cursor VS Code extension marketplace," Cursor explained.
The attack did not compromise Anthropic's legitimate extension or Open VSX, the extension marketplace Cursor uses.
The malicious extensions, versions 2.1.312 and 2.1.313, were available for approximately 11 hours before Cursor removed them.
As BleepingComputer previously reported, the attackers modified the legitimate Claude Code extension to execute malicious JavaScript that attempted to install persistent SSH backdoors on developers' computers.
The malware collected system information, installed an attacker-controlled SSH key, attempted to enable SSH access, and configured persistence mechanisms to maintain remote access.
However, security researchers found coding errors that likely prevented the backdoor from working on many Windows and macOS systems where SSH was not already enabled.
Cursor estimates that up to 5,000 users who requested affected extension versions during the exposure window may have received the malicious builds.

[TITLE] "사람의 움직임, 휴머노이드 로봇에 이식한다"…엔비디아, 피지컬 AI 동작 변환 기술 오픈소스 공개
[LINK] https://www.aitimes.kr/news/articleView.html?idxno=42732
[PUBLISHED] 2026-11-14 19:16 KST

[TOPIC] 개발, 신기술, 규제

[REASON] 인간 움직임을 휴머노이드 관절 제어로 변환하는 오픈소스 공개
[FIELD] 신기술
[BODY]
오픈소스 ‘소마 리타기터’로 인간과 로봇의 신체 구조·관절 차이 보정…동작 데이터를 로봇 제어 학습에 활용
엔비디아(NVIDIA)가 사람의 움직임을 휴머노이드 로봇의 신체 구조에 맞게 변환하는 오픈소스 기술을 공개했다. 인간과 로봇 사이의 관절 구조, 신체 비율, 가동 범위 차이를 보정해 사람의 동작 데이터를 로봇 제어 정책 학습에 활용할 수 있도록 지원하는 기술이다.
사람의 행동을 학습해 실제 물리적 환경에서 움직이는 피지컬 AI(Physical AI) 개발에 필요한 동작 데이터 활용 기반을 확대할 것으로 기대된다.
엔비디아는 13일(현지시간) '소마 리타기터(SOMA Retargeter-다운)'의 동작 변환 원리와 구현 절차, 로봇 제어 정책 학습에 적용하는 방법을 공개했다. 개발자는 사람의 움직임을 로봇 관절의 위치와 각도로 변환하고, 시뮬레이션 환경에서 동작을 검증한 뒤 로봇 제어 모델 학습에 활용할 수 있다.
사람의 동작을 로봇에 적용하기 어려운 가장 큰 이유는 신체 구조의 차이다. 사람과 휴머노이드 로봇은 팔과 다리의 길이, 관절 배치, 회전 가능 범위가 서로 다르다. 사람이 자연스럽게 수행하는 걷기나 손 흔들기 같은 동작도 로봇이 그대로 따라 하면 균형이 무너지거나 관절의 움직임이 제한될 수 있다.
소마 리타기터는 이러한 문제를 해결하기 위해 인간의 동작 데이터를 공통 골격 표현 체계인 '소마 엑스(SOMA-X-다운)'를 기반으로 처리한다. 서로 다른 장비와 방식으로 수집된 동작 데이터를 공통 구조로 표현한 뒤, 대상 로봇의 신체 비율과 관절 특성에 맞춰 변환하는 방식이다.
동작 변환에는 역운동학(Inverse Kinematics, IK) 기술이 사용된다. 손이나 발 등 신체 부위가 목표 위치에 도달하도록 각 관절의 각도를 계산하는 방법이다. 엔비디아는 자사의 워프(NVIDIA Warp)를 기반으로 구축된 뉴턴(Newton)의 역운동학 기능을 활용해 로봇의 관절 자세를 계산한다.
변환 과정에서는 로봇의 관절 가동 범위와 기준 자세를 반영하고, 발이 지면에 닿아 있는 동안 미끄러지는 현상을 줄이는 보정도 수행한다. 사람이 걷는 모습을 단순히 복제하는 것이 아니라 로봇이 수행할 수 있는 동작으로 재구성하는 데 초점을 맞췄다.
유니트리·부스터·애지봇 등 5종 휴머노이드 동작 변환 지원
엔비디아가 소개한 소마 리타기터 버전 0.2에는 서로 다른 신체 구조를 가진 휴머노이드 로봇 5종의 참조 설정과 동작 변환 사례가 포함됐다. 지원 대상은 유니트리(Unitree)의 G1과 H2, 부스터(Booster)의 T1, 애지봇(AgiBot)의 X2 울트라와 A3T3다.
개발자는 제공된 설정을 활용해 사람의 동작을 각 로봇의 관절 구조에 맞게 변환할 수 있다. 새로운 로봇을 적용할 때는 '로봇 컨피규레이터(Robot Configurator)'를 이용해 신체 비율과 기준 자세, 관절 대응 관계를 설정한다.
엔비디아는 부스터 T1의 손 흔들기 동작을 사례로 제시했다. 사람의 기준 자세와 로봇의 기준 자세가 일치하지 않으면 한 손을 흔드는 동작이 양팔을 벌린 자세로 변환될 수 있다. 기준 자세를 정렬하면 한쪽 손은 머리 옆에서 흔들고 다른 팔은 자연스럽게 내리는 움직임으로 보정된다.
또한 실험적인 역운동학 가중치 최적화 기능을 제공해 로봇이 여러 신체 부위의 목표 움직임을 동시에 충족하기 어려울 때 어떤 관절과 동작을 우선할지 조정할 수 있도록 했다.
모션캡처·동영상·생성형 AI 동작 데이터까지 활용
소마 리타기터는 다양한 출처의 인간 동작 데이터를 로봇 학습에 연결할 수 있다는 점도 특징이다. 모션캡처 데이터셋 '본즈 시드(BONES-SEED-다운)'에 수록된 사람의 움직임을 활용할 수 있으며, 단일 영상에서 전신의 3차원 움직임을 복원하는 '젬 엑스(GEM-X-다운)'와도 연계된다.
생성형 AI 기반 동작 생성 모델인 '키모도(Kimodo-다운)'와 '아르디(ARDY-다운)'가 만든 움직임도 활용할 수 있다. 키모도는 텍스트 설명과 자세 제약을 바탕으로 동작 시퀀스를 생성하고, 아르디는 움직임이 진행되는 동안 동작 방향을 대화형으로 조정할 수 있도록 지원한다. 개발자는 이러한 데이터를 소마 골격 표현으로 통일한 뒤 대상 로봇에 맞게 변환할 수 있다. 변환 결과는 프레임별 로봇의 위치와 방향, 관절 각도를 포함한 CSV 파일로 저장된다.
여러 동작을 변환해 축적하면 로봇 제어 모델 학습에 필요한 동작 라이브러리를 구성할 수 있다. 개별 동작을 반복적으로 수작업 조정하지 않고 대량의 데이터를 처리하는 배치 변환 기능도 제공된다.
로봇 제어 정책 학습과 연결...시뮬레이션에서 동작 검증
엔비디아는 소마 리타기터로 생성한 동작 데이터를 로봇 제어 정책 학습에 활용하는 절차도 공개했다. 로봇 제어 정책은 목표 동작과 로봇의 현재 상태를 입력받아 실제 관절을 움직이기 위한 제어 명령을 학습하는 모델이다. 소마 리타기터가 생성한 관절 궤적은 이러한 학습의 기준 동작으로 사용된다.
엔비디아의 소닉(SONIC) 학습 워크플로는 유니트리 G1용 변환 도구(다운)를 제공하며, 프로토모션스(ProtoMotions-다운)와 같은 물리 기반 동작 추적 프레임워크에서도 활용할 수 있다. 학습된 제어 정책은 시뮬레이션 환경에서 균형 유지, 지면 접촉, 구동기 한계, 목표 동작 추적 정확도 등을 평가할 수 있다.
엔비디아는 소형 로봇 '마이크로덕(MicroDuck)'에 사람의 동작을 변환해 적용하고, 물리 시뮬레이션에서 동작 추적 제어기를 학습한 사례도 소개했다. 사람의 원본 움직임과 변환된 로봇 동작, 학습된 제어기가 수행하는 움직임을 비교해 동작 변환과 정책 학습의 연결 과정을 보여줬다.
실시간 동작 생성 기술과의 연계도 가능하다. 엔비디아의 '모션브릭스(MotionBricks-보기)'는 목표 자세가 달라지는 상황에서 전신 움직임을 연속적으로 생성하는 기술이다. 유니트리 G1용 모델은 소마 리타기터로 변환한 인간 동작 데이터를 일부 학습에 활용했다.
사람의 시연 데이터를 로봇 학습 자산으로...피지컬 AI 개발 기반 확대
소마 리타기터의 기술적 의미는 사람의 움직임을 서로 다른 로봇에 적용할 수 있는 학습 데이터로 전환하는 과정에 있다.
휴머노이드 로봇의 행동 학습에는 다양한 동작 데이터가 필요하지만, 실제 로봇을 이용해 모든 동작을 수집하려면 상당한 시간과 비용이 소요될 수 있다. 기존 인간 모션캡처 데이터나 영상에서 복원한 움직임을 재활용하면 로봇별 동작 데이터 구축에 필요한 작업을 줄일 가능성이 있다.
특히 공통 골격 표현과 로봇별 변환 설정을 결합한 구조는 동일한 인간 동작 데이터를 신체 구조가 다른 여러 휴머노이드에 적용할 수 있도록 지원한다.
다만 소마 리타기터는 사람의 동작을 로봇의 관절 궤적으로 변환하는 도구로, 변환 결과가 실제 로봇에서 안정적으로 실행된다는 사실을 자동으로 보장하지는 않는다. 로봇의 균형과 지면 접촉, 구동기 제약을 고려한 제어 정책 학습과 검증 과정이 별도로 필요하다.
엔비디아는 이번 기술 블로그(보기)에서 구체적인 구현 방법과 활용 사례를 제시했지만, 특정 로봇의 작업 성공률이나 학습시간 단축률에 대한 새로운 정량적 성능 비교 결과는 발표하지 않았다.
한편, 소마 리타기터(다운)는 오픈소스로 제공되며, 개발자는 공식 저장소에서 설치 방법과 로봇별 참조 설정, 동작 변환 예제, 배치 처리 지침 등을 확인할 수 있다. 엔비디아는 로봇 개발자가 다양한 인간 동작 데이터를 활용해 제어 정책을 학습하고 검증할 수 있도록 관련 도구와 개발 절차를 지속적으로 제공하고 있다.

Runway's open-source Praxis-1 turns video AI into a robot controller
Key Points
- Runway has released its robot model Praxis-1 with open weights and source code under the Apache 2.0 license.
- Trained on videos and robot data, the model processes camera images, text instructions, and position data to calculate matching robot movements.
- Praxis-1 can be adapted to new robot systems through additional training, according to Runway. The model does occasionally confuse similar-looking objects, though, and it can't yet reliably plan complex action sequences on its own.
AI company Runway has released its robot model Praxis-1 with open weights and source code. The model uses what it learned from video to control robots and shows promising results in the company's own tests.
Runway has released Praxis-1, its AI model for controlling robots. The company first introduced Praxis-1 in late September but initially gave access only to select partners. Alongside the release, Runway published a detailed research report with new performance tests.
Runway's model weights and source code are available under the Apache 2.0 license, which allows commercial use.
Praxis-1 takes in camera images, text instructions, and information about a robot's position. From those inputs, it predicts how the environment will change and calculates the right robot movements. As new camera frames come in, the model continuously adjusts its control.
Praxis-1 builds on video training to control robots
Praxis-1 builds on a video model that learned how objects move and interact from ordinary footage. Runway then fine-tuned it with videos of human actions and robot data. This approach could reduce the need for expensive robot-specific datasets, which have traditionally been collected just to train these kinds of systems.
Runway is best known for generative video models like Gen-4.5. With Praxis-1, the company is bringing its video research into robotics. Runway calls Praxis-1 a World Action Model that predicts how a scene will change and derives matching robot movements from those predictions. Since September, robotics companies Standard Bots, Noble Machines, and Ultra have been testing Praxis-1 on different systems, including a humanoid robot, an industrial robot arm, and a dual-arm warehouse robot.
Praxis-1 leads among World Action Models
Praxis-1 still needs some specialized robot data. To adapt it to a Franka robot arm, Runway used about 277 hours of recordings from the public DROID research dataset, according to its research report. Those recordings show robots grasping and moving objects, for example. For a dual-arm robot, the company used between 1,400 and 2,600 hours of training material. Runway had already used DROID data and data from other robot systems during earlier training stages. Whether the approach actually needs less robot data overall than comparable models without general video pretraining is still an open question.
On Nvidia's RoboLab-120 leaderboard, Praxis-1 scores a 46.2 percent success rate. The benchmark tests how reliably robot models can sort, grasp, or stack objects across 120 tasks in simulation. FLUX 3 Action, also built as a World Action Model, scores 42.9 percent under the same test conditions. That puts Praxis-1 at the top of the World Action Model category. In the overall leaderboard, it ranks fifth behind two AI agents and two robot models with different architectures. Runway ran all the tests itself, and the results haven't been independently verified yet.
After fine-tuning on DROID data, Runway tested the model on a real Franka robot arm. Both models had to complete the same ten tasks, like placing a banana on a plate or closing a drawer. With ten attempts per task, Praxis-1 succeeded 88 times, while FLUX 3 Action managed 80.
Runway also tested how well Praxis-1 transfers to a robot type it had never seen before, using data from a mobile robot platform with a gripper arm that Google had previously used to develop RT-1.

[SCORE] 7
[REASON] 오픈소스 IRC 서버 결함의 실제 공격 악용으로 긴급 패치 필요
[FIELD] 보안
[BODY]
The U.S. Cybersecurity and Infrastructure Security Agency (CISA) on Friday added a high-severity security flaw impacting UnrealIRCd, an open-source Internet Relay Chat (IRC) server, to its Known Exploited Vulnerabilities (KEV) catalog, following reports of active exploitation.
The vulnerability, tracked as CVE-2026-114713 (CVSS score: 8.6), is a case of improper neutralization of delimiters that could be used to execute arbitrary commands with server/IRCOp privileges.
"The labeled-response module in UnrealIRCd 6.0.0 before 6.2.7.1 does not escape the IRCv3 'label' message tag when echoing it into replies, which allows any user on a network with two or more linked servers to inject server-to-server commands that are executed with server authority," reads the description of the flaw in the NIST National Vulnerability Database (NVD).
The addition comes nearly a week after UnrealIRCd's project leader, developer, and maintainer, Bram Matthys (aka Syzop), released UnrealIRCd 6.2.7.1 to address multiple security vulnerabilities identified with the help of artificial intelligence, including CVE-2026-114713.
"We are seeing bad guys exploiting this issue on the internet right now," Matthys said. "Hopefully everyone has hot-patched or updated their server, or at the very least has the spamfilter workaround deployed. If not, do so ASAP!"
Exploitation attempts are said to have commenced a day after the release of the hotfix on November 7, 2026. That said, the exact details of the malicious activity and its end goals are presently unknown. The maintainer described the vulnerability as the "most critical issue" found in UnrealIRCd over the past 15 years.
Federal Civilian Executive Branch (FCEB) agencies have time until November 16, 2026, to apply the fixes under Binding Operational Directive (BOD) 26-04: Prioritizing Security Updates Based on Risk.

아마존이 자사에서 판매하지 않는 제품까지 전 세계 상품 정보를 모으는 방안을 검토하고 있다. 소비자가 제품을 비교하기 위해 다른 사이트로 이동하는 일을 줄이고, 구매를 대신하는 외부 AI 에이전트도 아마존을 찾도록 하려는 구상이다.
로이터는 13일(현지시간) 내부 문서와 관계자들을 인용해 아마존이 ‘월드 프로덕트 그래프(World Product Graph)’라는 프로젝트를 추진하고 있다고 보도했다.
브랜드에서 제공받는 정보와 다른 유통 사이트에서 수집한 데이터를 결합해 상품 간 차이와 관계를 파악하는 것이 목표다. 이용자가 최신 모델을 구별하거나 자신에게 맞는 제품을 고를 때 필요한 정보를 아마존 안에서 찾도록 한다는 것이다.
상품 정보를 수집하기 위해 다른 업체의 웹사이트를 자동으로 탐색하는 방식도 구상에 포함됐다. 다른 업체의 웹사이트에서 어떤 방식으로 정보를 수집할지, 이 과정에서 각 업체의 허가를 받아야 하는지는 확인되지 않았다.
자체 AI 쇼핑 도우미의 정확도를 높이고 운영 비용을 줄이려는 목적도 담겼다. 내부 문서는 기존 ‘루퍼스’의 답변에 오류와 누락이 있으며, 상품 정보를 보강하면 저렴한 모델을 효율적으로 사용할 수 있다고 설명했다.
이에 대해 아마존은 현재 AI 쇼핑 도우미인 ‘알렉사 포 쇼핑’의 답변 정확도가 자체 집계 기준 약 97%라고 설명했다. 내부 문서에서 지적한 오류 문제가 현재 서비스 수준을 그대로 보여주는 것은 아니라는 취지다. 알렉사 포 쇼핑은 기존 ‘루퍼스’의 이름을 지난 5월 바꾼 서비스다.
외부 AI 에이전트가 상품을 비교해 다른 쇼핑몰에서 구매하도록 안내하면, 소비자가 아마존을 방문하거나 광고를 볼 기회가 줄어들 수 있다. 관계자들은 아마존이 폭넓은 상품 정보를 갖추면 외부 AI 에이전트도 제품을 찾고 비교할 때 아마존을 이용하도록 유도해 광고 사업을 지킬 수 있다고 설명했다.
아마존은 이미 외부 쇼핑몰 상품을 보여주는 ‘숍 다이렉트(Shop Direct)’와 구매를 대신하는 ‘바이 포 미(Buy for Me)’를 운영하고 있다. 이용자는 판매자 사이트로 이동해 직접 구매하거나, 일부 상품은 아마존의 AI 구매 기능을 통해 주문할 수 있다.
이번 구상은 외부 상품을 연결하는 기존 서비스에 비교·추천에 필요한 정보를 보강하려는 움직임으로 해석된다. AI 쇼핑 경쟁에서 상품 판매뿐 아니라 소비자의 선택과 구매를 연결하는 역할까지 확보하려는 전략이다.
내부 문서에는 내년 10월1일 출시를 목표로 제시했지만, 실행 여부와 일정은 확정되지 않았다. 아마존은 오래된 검토 문서로 현재 계획과 다를 수 있다고 밝혔다.

- 출처 상태는 릴리스 파일의 증명 보유 여부로 계산함. 증명이 없다는 사실만으로 악성 파일인 것은 아니며, 파일의 출처를 암호학적으로 검증할 수 없다는 뜻임
- 일부 파일에만 증명이 있거나, 같은 릴리스의 파일이 서로 다른 저장소나 빌드 시스템에서 만들어지면 경고를 표시함. 이전 릴리스와 비교해 저장소나 워크플로가 바뀌거나 증명이 사라진 경우도 알림
- 프로젝트 상세 페이지는 출처 경고를 상단에 표시하고, 메타데이터를 검증 여부 대신 유용성에 따라 정렬함
- 릴리스 파일 탭에 검색과 필터링, 파일별 출처 상태가 추가됨. 릴리스 이력 탭에서도 파일 수, 출처 상태, 릴리스 상태를 확인할 수 있음
개편 목적과 보안 신호
새 보안 탭과 출처 상태
- 보안 탭은 릴리스의 출처 상태와 파일별 증명을 모아 릴리스 파일이 어디에서 왔는지 확인하는 전용 공간임
- 각 릴리스의 출처 상태는 파일마다 증명이 있는지 확인해 계산하며, 일반적으로 다음 두 상태 중 하나임
  - Full Provenance: 릴리스 파일 100%에 지원되는 증명 유형 중 하나 이상이 있음
  - No Provenance: 릴리스의 어떤 파일에도 증명이 없음
- 지원하는 증명 유형은 두 가지임
- 증명 메타데이터는 UI에서 직접 확인할 수 있으며, 투명성 로그 링크에서 추가 정보를 볼 수 있음
- No Provenance는 악성 판정이 아님. 오래된 릴리스나 Trusted Publishing을 아직 설정하지 않은 프로젝트에서 흔하며, 파일 출처를 암호학적으로 검증할 수 없다는 뜻임
출처 경고의 유형과 확인 방법
- 출처 경고는 계정이나 게시 워크플로 탈취 등으로 파일이 프로젝트 유지관리자에게서 오지 않았을 가능성을 파악하도록 도움
  - 출처 메타데이터가 비정상적이거나 프로젝트 이력과 충돌하면 눈에 띄는 경고를 표시함
  - 정상적인 이유가 있는 경고도 많지만, 각각 설치 전에 확인할 필요가 있음
- Incomplete Provenance는 일부 파일에만 증명이 있는 상태임
  - 예를 들어 wheel은 Trusted Publishing으로 게시했지만 소스 tarball은 API 토큰으로 업로드한 경우임
  - 설치 전에 릴리스 노트에서 빌드 문제를 확인하거나 프로젝트 이슈 트래커에 문의해야 함
- Inconsistent Provenance는 같은 릴리스의 파일들이 서로 다른 빌드 시스템이나 소스 저장소에서 왔다는 뜻임
  - 증명 메타데이터를 확인해 모든 파일이 유지관리자가 통제하는 출처에서 왔는지 점검해야 함
- Change of Provenance는 이전 릴리스와 다른 저장소나 워크플로에서 파일이 생성됐다는 뜻임
  - 조직 이름 변경이나 저장소 이전처럼 정상적인 경우가 많지만, 파이프라인 침해나 계정 탈취의 신호일 수도 있음
  - 릴리스 노트나 공식 채널에서 예정된 인프라 이전인지 확인해야 함
- Loss of Provenance는 이전에 증명을 포함해 게시하던 프로젝트가 증명 없이 파일을 업로드하기 시작했다는 뜻임
  - API 토큰으로 되돌아갔거나 증명을 생성하지 않도록 설정을 바꾸는 등 의도적인 게시 절차 변경인지 확인해야 함
  - 예상하지 못한 변경이라면 검증될 때까지 해당 릴리스를 의심해야 함
- 출처와 증명, 경고에 대한 추가 안내는 사용자 문서에서 확인할 수 있음
프로젝트 상세 페이지와 메타데이터
- 출처 경고는 페이지 상단에 철회된 릴리스, 보관 처리된 프로젝트, 사전 릴리스 상태 배너와 함께 표시됨
  - 프로젝트나 릴리스가 격리된 상태라면 격리 배너만 표시하며, 다른 모든 경고와 배너보다 우선함
- 릴리스가 Full Provenance 상태이거나 출처 경고가 있으면 사이드바에 출처 상태를 표시하고 보안 탭으로 연결함
- 메타데이터는 기존의 검증 여부별 그룹화와 정렬 대신 유용성에 따라 정렬함
  - 각 항목에는 “PyPI data” 또는 “Data verified by PyPI” 라벨을 붙임
릴리스 파일과 릴리스 이력
- 개편된 릴리스 파일 탭은 긴 파일 목록을 검색하고 필터링할 수 있음
  - 표에서 파일별 출처 상태를 확인할 수 있음
  - 늦게 업로드된 파일은 주황색 경고 아이콘으로 표시함
- 지연 업로드 경고는 최초 릴리스 시각으로부터 14일이 지난 뒤 업로드된 파일이 하나 이상 있을 때 나타남
- 릴리스 이력 탭은 릴리스별 파일 수와 출처 상태를 보여줌
  - 격리, 철회, 보관 처리, 사전 릴리스 여부도 함께 확인할 수 있음
보안 안내 문서와 향후 활용
- PyPI 사용자 문서도 확장됐으며, 패키지 보안 가이드에서 다음 항목을 안내함
- 새 보안 탭은 향후 추가될 증명 유형과 보안 공지를 위한 전용 공간으로 활용할 수 있음
- 더 넓은 오픈소스 생태계에서도 활용할 수 있도록 이번 프로젝트의 디자인 패턴과 경고를 정리한 사례 연구를 OpenSSF Attestations Style Guide에 공개함

AT&T uses agentic AI to reinvent business processes from the ground up
AT&T Corp. is moving beyond using artificial intelligence to improve employee productivity, increasingly applying autonomous agents to redesign how its business operates. Nearly 500 agentic workflows are already in production, and the telecom giant plans to triple that number next year.
AT&T now processes about 45 billion AI tokens daily across the company, according to Luke Corbin (pictured, below), assistant vice president of digital transformation and AI at AT&T Business. Its agentic AI platform handles more than 1 million transactions monthly. Many of those workflows now operate autonomously, handling tasks ranging from customer provisioning to sales prospecting.
Speaking at an Amazon Web Services Inc. event in Boston earlier this month, Corbin said the company’s approach emphasizes rethinking entire processes rather than simply automating individual tasks. AT&T has moved quickly from experimenting with generative AI to systematically identifying business processes that can be redesigned around agentic capabilities.
At the heart of the transformation is Business Agent Foundry, a group established in early 2025 to work with individual business units. Rather than soliciting isolated automation ideas from employees, the foundry maps business processes using industry frameworks and identifies opportunities to eliminate unnecessary steps, organizational handoffs and legacy application dependencies, Corbin said.
One early initiative involved automating interactions with AT&T’s mainframe computers. Changes to customer fiber installation orders previously required employees to retrieve tickets from queues, manually update records and return them to the workflow.
Agentic automation eliminated portions of that manual process, reducing delays and accelerating service delivery.
“It was kind of cool having some of the most advanced technology talking to some of the oldest that we have,” Corbin said.
In another example, AT&T halved the time required to provision dedicated internet connections in buildings where fiber infrastructure was already installed.
A different approach
AT&T’s architecture breaks from conventional approaches that build large numbers of independent, specialized agents. Instead, the company maintains a relatively small set of agents that execute business workflows using centrally managed business logic.
“We store the business logic in context or in memory,” Corbin said.
Retrieval agents identify applicable knowledge, while planning agents determine the actions, tools and data needed to complete a task.
Governance is central to the process. Individual employees can independently create personal productivity agents, but workflows affecting customers must pass through the foundry and undergo security, privacy and compliance reviews.
“We’ve democratized agents to the point where people can use them for personal productivity, but not to where you would drive business workflows that could touch your customers or materially have an impact on your business,” Corbin said.
Every production workflow initially includes human oversight. Only after accuracy reaches the mid- to high 90% range within a permissible risk profile can agents operate autonomously. Continuous monitoring evaluates performance and detects drift.
Success metrics include labor savings, revenue generation, operating costs and customer satisfaction. Corbin said production AI investments are achieving fivefold returns within a year.
A 151-year-old company that has been using computers since they were invented “is built on a lot of legacy processes and applications,” Corbin said. “The cost of maintaining those applications, training employees to use them and ongoing maintenance is very high. When you can offset some of that with simpler generative workflows, you’ve got a business case that’s built for itself.”
Sales prospecting is one beneficiary.
