- **날짜**: 2026-10-22 19:44 KST
- **주제**: 에이전트, 개발, 모델
- **중요도**: 8/10 - 악성 MCP 서버를 통한 OpenCode 원격 코드 실행 결함
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/10/opencode-flaw-lets-malicious-mcp.html)

**요약**

- A critical security flaw in the OpenCode AI coding agent allowed malicious or hijacked MCP servers to execute code on developers' Windows and WSL systems during sign-in.
- The vulnerability stemmed from passing unescaped OAuth authorization URLs to PowerShell via an outdated browser helper package, but developer Anomaly did not request a CVE.
- Developers using OpenCode on affected platforms must manually update to version 1.18.33 or remove untrusted remote MCP servers to secure their environments.

**번역**

- 오픈코드 AI 코딩 에이전트의 치명적 보안 결함으로 인해 악의적이거나 탈취된 MCP 서버가 개발자의 윈도우 및 WSL 시스템에서 로그인 시 임의 코드를 실행할 수 있었다.
- 이 취약점은 구버전 브라우저 헬퍼 패키지를 통해 이스케이프 처리되지 않은 OAuth 인증 URL을 파워셸로 넘기면서 발생했으나, 개발사 아노말리는 CVE를 요청하지 않았다.
- 영향을 받는 플랫폼에서 오픈코드를 사용하는 개발자는 환경을 보호하기 위해 1.18.33 버전 이상으로 직접 업데이트하거나 신뢰할 수 없는 원격 MCP 서버를 제거해야 한다.
