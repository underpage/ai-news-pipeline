- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/security/blackx-uefi-bootkit-exploits-baton-drop-flaw-to-bypass-secure-boot/)

**요약**

- A new UEFI bootkit dubbed BlackX exploited the Baton Drop vulnerability (CVE-2022-21894) to bypass Secure Boot and disrupt security software on Windows systems.
- Attributed to Chinese state-sponsored threat group APT41, the bootkit borrows exploit mechanisms from BlackLotus to load malicious drivers and deploy espionage payloads.
- The attack succeeded on fully patched Windows machines because administrators rarely trigger the manual Secure Boot certificate revocation required to close the mitigation gap.

**번역**

- BlackX라는 신종 UEFI 부트킷이 시큐어 부트를 우회하고 윈도우 시스템의 보안 소프트웨어를 무력화하기 위해 Baton Drop 취약점(CVE-2022-21894)을 악용했다.
- 중국 연계 해킹 그룹 APT41의 소행으로 추정되는 이 부트킷은 BlackLotus의 익스플로잇 메커니즘을 차용해 악성 드라이버를 로드하고 스파이웨어 페이로드를 배포했다.
- 해당 완화 조치 격차를 해소하는 데 필요한 시큐어 부트 인증서 수동 취소 조치를 관리자가 실행하는 경우가 드물었기 때문에 완전히 패치된 윈도우 환경에서도 공격이 성공했다.
