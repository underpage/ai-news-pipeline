## 1. Researchers broke the browsers built into VS Code, Cursor, Copilot, Codex and Claude Desktop

- **번역 제목**: 연구원들, VS Code, Cursor, Copilot, Codex, Claude Desktop 내장 브라우저 격리 우회 성공

- **주제**: 개발, 보안
- **중요도**: 9/10 - 주요 AI 코딩 어시스턴트 내장 브라우저 격리 우회 취약점
- **태그**: 부정
- **출처**: Help Net Security
- **링크**: [원문 기사](https://www.helpnetsecurity.com/2026/10/29/research-ai-assistant-browser-vulnerabilities/)

**요약**

- Forever Security discovered EMBRACE vulnerabilities in built-in browsers across five major AI coding assistants including VS Code, Cursor, Copilot, Codex, and Claude Desktop.
- Vendors weakened embedded browser security rules to support local project previews, enabling attackers to execute code or read arbitrary disk files including SSH keys and credentials.
- While Cursor patched its flaw and GitHub Copilot addressed issues, Codex and VS Code remained unpatched as vendors cited Workspace Trust prompts that offer little practical protection.

**번역**

- 포에버 시큐리티는 VS Code, Cursor, Copilot, Codex, Claude Desktop 등 5개 주요 AI 코딩 어시스턴트의 내장 브라우저에서 EMBRACE 취약점을 발견했다.
- 벤더들이 로컬 프로젝트 미리보기를 위해 내장 브라우저 보안 규칙을 완화하면서 공격자가 코드를 실행하거나 SSH 키와 자격 증명을 포함한 디스크 파일을 읽을 수 있게 되었다.
- Cursor는 취약점을 패치하고 GitHub Copilot도 문제를 처리했으나, Codex와 VS Code는 실제 보호 효과가 거의 없는 작업 영역 신뢰 프롬프트를 이유로 미패치 상태로 남았다.

- **태그**: 긍정
- **출처**: SecurityWeek
- **링크**: [원문 기사](https://www.securityweek.com/cisco-open-sources-quarry-to-catch-ai-agent-attacks-hidden-in-harmless-steps/)

**요약**

- Cisco open-sourced Project Quarry, a neurosymbolic rule language designed to catch AI agent attacks hidden across sequences of individually benign actions.
- Quarry combines machine learning judgment with symbolic rule checks to detect cross-step malicious patterns that bypass traditional single-action security controls.
- Defenders and coding agents can write and test rules to scale responses against evolving multi-step threats, equalizing the cybersecurity asymmetry.

**번역**

- 시스코는 개별적으로는 무해한 일련의 단계에 숨겨진 AI 에이전트 공격을 포착하기 위해 뉴로심볼릭 규칙 언어인 프로젝트 쿼리를 오픈소스화했다.
- 쿼리는 머신러닝 판단과 심볼릭 규칙 검사를 결합해 전통적인 단일 작업 보안 제어를 우회하는 단계 간 악의적 패턴을 탐지한다.
- 방어자와 코딩 에이전트는 진화하는 다단계 위협에 대응할 규칙을 작성하고 테스트하여 사이버 보안의 비대칭성을 해소할 수 있다.
