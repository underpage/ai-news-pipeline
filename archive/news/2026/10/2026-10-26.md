## 1. AI coding agents hijacked using AGENTS.md file in Downloads folder

- **번역 제목**: 다운로드 폴더의 AGENTS.md 파일을 이용해 AI 코딩 에이전트 탈취
- **날짜**: 2026-10-26 00:49 KST
- **주제**: 에이전트, 개발
- **중요도**: 9/10 - 다운로드 폴더 지침 파일 조작을 통한 코딩 에이전트 탈취 공격 발견
- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/security/ai-coding-agents-hijacked-using-agentsmd-file-in-downloads-folder/)

**요약**

- Researchers discovered that malicious markdown instruction files like AGENTS.md in a user's Downloads folder can hijack AI coding agents to install rogue packages or steal credentials.
- The attack was demonstrated against OpenAI Codex and Claude Code, where agents automatically read and executed instructions from the working directory without any software bugs in the models themselves.
- Because web browsers can silently download files into the Downloads directory where hundreds of users launch AI agent sessions, this attack vector poses a significant practical security risk.

**번역**

- 연구진은 사용자의 다운로드 폴더에 있는 AGENTS.md와 같은 악성 마크다운 지침 파일이 악성 패키지를 설치하거나 자격 증명을 탈취하도록 AI 코딩 에이전트를 조작할 수 있음을 발견했다.
- 이 공격은 OpenAI Codex와 Claude Code를 대상으로 입증되었으며, 모델 자체의 소프트웨어 결함 없이도 에이전트가 작업 디렉터리의 지침을 자동으로 읽고 실행하면서 발생했다.
- 웹 브라우저가 다운로드 디렉터리에 파일을 사용자 모르게 저장할 수 있고 수백 명의 사용자가 해당 폴더에서 AI 에이전트 세션을 실행하고 있어, 이 공격 경로는 실질적인 보안 위험을 초래한다.

- **출처**: InfoQ

**요약**

- Google and Meta open-sourced TorchTPU, a native PyTorch backend for Google Cloud TPUs, allowing models to run on TPUs by simply changing the device target to tpu.
- TorchTPU replaces PyTorch/XLA and integrates directly into PyTorch's dispatcher, natively supporting Hugging Face models, vLLM, SGLang, and TorchTitan while scaling near-linearly across more than 8,000 chips.
- To help developers optimize models originally skewed toward GPU architectures, Google also introduced the TPU agent suite to automate onboarding and performance tuning.

**번역**

- 구글과 메타는 장치 대상을 tpu로 변경하는 것만으로 구글 클라우드 TPU에서 모델을 실행할 수 있게 해주는 네이티브 파이토치 백엔드 TorchTPU를 오픈소스화했다.
- TorchTPU는 PyTorch/XLA를 대체하고 파이토치 디스패처에 직접 통합되어 Hugging Face 모델, vLLM, SGLang, TorchTitan을 기본 지원하며 8,000개 이상의 칩에서 거의 선형적인 확장을 보여준다.
- GPU 아키텍처에 맞춰진 모델을 최적화할 수 있도록 지원하기 위해, 구글은 온보딩과 성능 튜닝을 자동화하는 TPU 에이전트 스위트도 함께 발표했다.

## 3. Google ML Drift Accelerates On-Device AI Inference Across Diverse GPUs

- **번역 제목**: 구글 ML Drift, 다양한 GPU 전반에서 온디바이스 AI 추론 가속화
- **날짜**: 2026-10-26 02:00 KST
- **주제**: 개발, 모델, 신기술
- **중요도**: 8/10 - 온디바이스 AI 추론을 위한 크로스플랫폼 GPU 엔진 오픈소스화
- **태그**: 긍정
- **출처**: InfoQ
- **링크**: [원문 기사](https://www.infoq.com/news/2026/10/google-ml-drift/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)

**요약**

- Google released ML Drift, an open-source, cross-platform GPU compute engine under the Apache 2.0 license designed to accelerate on-device AI inference across various hardware architectures.
- ML Drift powers LiteRT and replaces the legacy TFLite GPU delegate, adding native 5D tensor support, extensible custom operations, and unified shaders via WebGPU, Metal, OpenCL, and OpenGL ES.
- The engine is already deployed on millions of devices in apps like YouTube Shorts and Google Photos, showing up to a 40% reduction in latency and a 12% lower memory overhead compared to other local frameworks.

**번역**

- 구글은 다양한 하드웨어 아키텍처 전반에서 온디바이스 AI 추론을 가속화하도록 설계된 아파치 2.0 라이선스 기반의 오픈소스 크로스플랫폼 GPU 연산 엔진 ML Drift를 공개했다.
- ML Drift는 LiteRT를 구동하며 기존 TFLite GPU 델리게이트를 대체하여, WebGPU, Metal, OpenCL, OpenGL ES를 통해 5차원 텐서 네이티브 지원, 확장 가능한 커스텀 연산, 통합 셰이더를 추가했다.
- 이 엔진은 이미 유튜브 쇼츠와 구글 포토 등 수백만 대 기기의 앱에 적용되어 지연 시간을 최대 40% 단축하고 다른 로컬 프레임워크 대비 메모리 오버헤드를 12% 낮췄다.
