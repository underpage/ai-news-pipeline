## 5. Attackers Exploit CVSS 10.0 Bricksforge WordPress Flaw Enabling Unauthenticated RCE

- **번역 제목**: 공격자들, 인증되지 않은 RCE를 가능하게 하는 CVSS 10.0 Bricksforge 워드프레스 취약점 익스플로잇
- **날짜**: 2026-10-12 18:02 KST
- **주제**: 개발, 보안
- **중요도**: 9/10 - WordPress 플러그인 치명적 취약점 악용
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/10/attackers-exploit-cvss-100-bricksforge.html)

**요약**

- A maximum-severity security flaw, CVE-2026-85097, in the Bricksforge WordPress plugin is under active exploitation in the wild.
- The vulnerability allows unauthenticated attackers to upload and execute arbitrary PHP code, leading to remote code execution (RCE) on affected websites.
- Attackers exploit insufficient validation of a URL field in the 'temporaryFileUploads' parameter to achieve RCE, even bypassing extension filtering.

**번역**

- Bricksforge 워드프레스 플러그인의 최대 심각도 보안 취약점인 CVE-2026-85097이 실제 환경에서 적극적으로 익스플로잇되고 있다.
- 이 취약점은 인증되지 않은 공격자가 임의의 PHP 코드를 업로드하고 실행하여 영향을 받는 웹사이트에서 원격 코드 실행(RCE)을 초래할 수 있도록 한다.
- 공격자들은 'temporaryFileUploads' 매개변수의 URL 필드에 대한 불충분한 유효성 검사를 익스플로잇하여 확장자 필터링을 우회하면서 RCE를 달성한다.

**요약**

- GitLab has warned users to immediately patch a maximum-severity code execution vulnerability, CVE-2026-97229, in its CI/CD Regular Expression Compiler.

- 정수 오버플로 약점인 이 취약점은 인증되지 않은 원격 공격자가 특수하게 조작된 정규 표현식을 통해 대상 인스턴스에서 임의 코드를 실행할 수 있도록 한다.
- GitLab은 커뮤니티 에디션(CE) 및 엔터프라이즈 에디션(EE) 버전에 대한 패치를 릴리스했으며, 시스템 보안을 위해 즉시 업그레이드할 것을 강력히 권고한다.
