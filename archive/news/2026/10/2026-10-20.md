## 2. WordPress SEO plugin Rank Math compromised to backdoor websites

- **날짜**: 2026-10-20 06:24 KST
- **주제**: 보안
- **중요도**: 9/10 - 인기 워드프레스 플러그인 변조를 통한 백도어 공급망 공격
- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/security/wordpress-seo-plugin-rank-math-compromised-to-backdoor-websites/)

**요약**

- Downloads of the Rank Math PRO WordPress plugin from its official website were trojanized in a supply-chain attack to install hidden backdoors.
- The compromised version 3.0.123 distributed during an 11-hour window exposed database credentials, API keys, and cloud secrets while establishing persistent access.
- Rank Math removed the malicious files and released a clean v3.0.124 update, urging affected administrators to conduct thorough manual cleanups and secret rotations.

**번역**

- 공식 웹사이트에서 배포된 워드프레스 검색 엔진 최적화 플러그인 Rank Math PRO의 다운로드 파일이 공급망 공격을 받아 숨겨진 백도어를 설치하도록 변조됐다.
- 11시간 동안 배포된 침해된 3.0.123 버전은 지속적인 접근 권한을 확보하는 동시에 데이터베이스 자격 증명, API 키, 클라우드 기밀을 노출시켰다.
- Rank Math는 악성 파일을 제거하고 정상적인 3.0.124 업데이트를 배포하며, 영향을 받은 관리자들에게 철저한 수동 정리와 기밀 교체를 권고했다.

- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/security/f5-releases-out-of-band-patches-for-critical-nginx-vulnerabilities/)

**요약**

- F5 released out-of-band security updates for multiple NGINX products to remediate three critical vulnerabilities that allow remote code execution or denial of service.
- The flaws in the ngx_http_v3_module and map directive can trigger heap buffer overflows or use-after-free conditions, potentially enabling arbitrary code execution.
- Given past targeting of F5 software by advanced threat groups, administrators unable to patch immediately should implement the vendor's configuration mitigations.

**번역**

- F5가 원격 코드 실행이나 서비스 거부 공격을 유발할 수 있는 세 건의 치명적인 취약점을 해결하기 위해 여러 NGINX 제품을 대상으로 대역 외 보안 업데이트를 공개했다.
- ngx_http_v3_module 및 map 지시어의 결함은 힙 버퍼 오버플로우나 Use-After-Free를 일으켜 임의 코드 실행으로 이어질 위험이 있다.
- 과거 지능형 위협 조직들이 F5 소프트웨어를 집중 공격했던 점을 고려할 때, 즉각 패치가 어려운 관리자는 제조사가 제시한 설정 완화책을 적용해야 한다.
