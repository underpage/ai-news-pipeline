**요약**

- Next.js released an out-of-band security update addressing two critical unauthenticated remote code execution flaws and one high-severity denial-of-service flaw.
- The flaws exist in React Server Components caching and the librsvg library used via the sharp package for SVG image rendering.
- Vercel recommends upgrading to Next.js 16.4.1 or 15.5.28, noting that version 15 users must also ensure the sharp package is updated to 0.35.5 or later.

**번역**

- Vercel은 Next.js 16.4.1 또는 15.5.28 버전으로 업그레이드할 것을 권고하며, 15 버전 사용자는 sharp 패키지가 0.35.5 이상으로 업데이트되었는지도 확인해야 한다.

## 5. Hackers hijacked 1,900 GitHub accounts. Then they went after 30,000 repos.

- **번역 제목**: 해커들, 1,900개 GitHub 계정 탈취 후 30,000개 리포지토리 공격
- **날짜**: 2026-10-16 06:13 KST
- **주제**: 보안
- **중요도**: 9/10 - 1,900개 깃허브 계정 탈취 후 3만여 저장소에 자격증명 탈취 코드 주입
- **태그**: 부정
- **출처**: The New Stack
- **링크**: [원문 기사](https://thenewstack.io/hackers-hijacked-1900-github-accounts-then-they-went-after-30000-repos/)

**요약**

- Attackers hijacked approximately 1,900 GitHub accounts to inject credential-stealing GitHub Actions workflows into more than 30,000 repositories in the GhostAction campaign.
- The disguised malicious workflows used actions/checkout with fetch-depth: 0 to scan Git histories for cloud keys, personal access tokens, and AI provider API keys.
- While GitHub controls blocked many workflows, attackers targeted 3,174 secrets, making it crucial to revoke compromised accounts and rotate exposed credentials.

**번역**

- 공격자들은 GhostAction 캠페인을 통해 약 1,900개의 GitHub 계정을 탈취한 뒤 30,000개 이상의 리포지토리에 자격증명을 탈취하는 GitHub Actions 워크플로우를 주입했다.
- 위장된 악성 워크플로우는 fetch-depth: 0 설정의 actions/checkout을 사용하여 클라우드 키, 개인 액세스 토큰 및 AI 제공업체 API 키를 Git 기록에서 검색했다.
- GitHub의 통제로 많은 워크플로우가 차단되었으나 공격자들은 3,174개의 시크릿을 노렸으므로 침해된 계정을 취소하고 노출된 자격증명을 교체하는 조치가 필수적이다.

- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/10/critical-pwnescape-linux-kernel.html)

**요약**

- A critical Linux kernel vulnerability tracked as CVE-2026-99999 and named PwnEscape allows code within a virtual machine to read host computer memory.
- Discovered in a Vercel security challenge using AI-assisted tooling, the networking flaw was shown to leak host memory, crash the host, and achieve host root escape in a lab environment.

**번역**

- 이 취약점은 클라우드 제공업체들이 공유하는 커널 네트워킹 계층에서 발생하며, 패킷 체크섬 데이터 오프셋 문제를 방지하기 위한 메인라인 커널 패치가 병합되었다.

**요약**

- NGINX released versions 1.30.6 and 1.31.7 to fix five vulnerabilities, including three high-severity memory bugs and a TLS flaw.

- 각 결함은 정규식 맵이나 공유 세션 캐시와 같은 특정 설정을 요구하며, F5와 NGINX는 최신 패치 버전으로 업그레이드할 것을 권고한다.
