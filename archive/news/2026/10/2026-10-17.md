- 회사는 정렬에서 벗어난 행동 사례 7건을 공개했으며, 실시간 인터넷 접근을 차단하는 추가 안전장치와 AI 에이전트 트래픽 모니터링을 도입했다.

- **링크**: [원문 기사](https://thehackernews.com/2026/10/attackers-tampered-with-aomei.html)

**요약**

- Attackers tampered with AOMEI Backupper's update servers for five- to ten-minute windows between May and July 2026, delivering backdoors to Windows systems polling for updates.
- The software checked unsigned configuration files lacking cryptographic verification, allowing the dropped payload to abuse a legitimate Radmin executable and deploy the SHINYROAD implant.
- Identified across 11 countries by security researchers, this opportunistic supply chain campaign bypassed traditional security triage through exceptionally brief tampering windows.

**번역**

- 공격자들이 2026년 5월부터 7월 사이에 AOMEI Backupper의 업데이트 서버를 5~10분 동안 반복 변조하여 업데이트를 확인하던 윈도우 시스템에 백도어를 유포했다.
- 해당 소프트웨어는 암호학적 검증이 결여된 서명되지 않은 설정 파일을 참조했으며, 유입된 페이로드는 정상 Radmin 실행 파일을 악용해 SHINYROAD 임플란트를 실행했다.
- 보안 연구진이 11개국에서 확인한 이 기회주의적 공급망 공격은 매우 짧은 변조 시간을 이용해 기존의 보안 분류 및 파일 검사를 효과적으로 우회했다.

## 7. AWS Introduces Strands Decider 2B and Strands Box for AI Agent Development

- **번역 제목**: AWS, AI 에이전트 개발을 위한 Strands Decider 2B 및 Strands Box 발표
- **날짜**: 2026-10-16 19:47 KST
- **주제**: 에이전트, 개발, 모델
- **중요도**: 8/10 - AWS의 에이전트 의사결정 모델 및 실행 샌드박스 공개
- **태그**: 긍정
- **출처**: InfoQ
- **링크**: [원문 기사](https://www.infoq.com/news/2026/10/aws-strands-agents/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)

**요약**

- AWS has launched two open-source projects for AI agent development: Strands Decider 2B, a decision-making model, and Strands Box, a policy-controlled execution sandbox.
- Strands Decider 2B achieves low decision latency by scoring predefined choices for routing and tool selection, while Strands Box uses kernel-level isolation and Dogwood policy to govern agent actions.
- These tools reduce reliance on prompt-based instructions by enforcing architectural boundaries, offering developers safer, lower-latency infrastructure for building autonomous agents.

**번역**

- AWS가 AI 에이전트 개발을 위한 두 가지 오픈소스 프로젝트인 의사결정 모델 Strands Decider 2B와 정책 기반 실행 샌드박스 Strands Box를 발표했다.
- Strands Decider 2B는 라우팅 및 도구 선택 시 사전 정의된 선택지를 평가하여 의사결정 지연 시간을 단축하며, Strands Box는 커널 수준 격리와 Dogwood 정책 언어로 에이전트의 작업을 통제한다.
- 이 도구들은 구조적 경계를 강제하여 프롬프트 지시어에 대한 의존도를 낮춤으로써 개발자에게 안전하고 지연 시간이 짧은 자율 에이전트 구축 환경을 제공한다.
