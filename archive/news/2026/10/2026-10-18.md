- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/10/malfex-npm-package-imgdecode-hides.html)

**요약**

- Security researchers discovered a malicious npm package named imgdecode that hides a shellcode loader inside a compiled Node.js addon targeting Windows systems.
- The package is part of the persistent MALFEX supply chain campaign, which circumvents npm takedowns by rapidly publishing alternative packages and using multi-stage execution chains.
- Attackers disguised malicious DLLs and Go binaries as normal dependencies and used image files to deliver encrypted shellcode into running system processes.

**번역**

- 보안 연구진이 윈도우 시스템을 겨냥해 컴파일된 노드JS 애드온 내부에 셸코드 로더를 숨긴 악성 npm 패키지 imgdecode를 발견했다.
- 해당 패키지는 npm의 삭제 조치에 대응해 대체 패키지를 즉시 재배포하고 다단계 실행 체인을 사용하는 지속적인 MALFEX 공급망 공격 캠페인의 일부이다.
- 공격자들은 악성 DLL과 Go 바이너리를 정상적인 의존성 모듈로 위장하고 이미지 파일에서 암호화된 셸코드를 추출해 실행 중인 시스템 프로세스에 주입했다.
