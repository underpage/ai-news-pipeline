[수동 요약]

- 약 471곳은 PolyShell(CVE-2026-48356) 취약점으로 로더가 주입된 것으로 추정되며, 사이트 운영자는 의심스러운 계정과 예상치 못한 CMS 블록을 점검하고 사이트를 최신 상태로 유지하라는 권고를 받았다.

## 10. Microsoft releases emergency .NET patches for critical Brotli flaw

- **번역 제목**: 마이크로소프트, 브로틀리 치명적 결함 막는 닷넷 긴급 패치 배포
- **날짜**: 2026-10-27 00:38 KST
- **주제**: 보안
- **중요도**: 7/10 - 닷넷의 브로틀리 결함 긴급 패치
- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-emergency-net-patches-for-critical-brotli-flaw/)

**요약**

[수동 요약]

- Microsoft released emergency .NET security updates for CVE-2026-111497, a critical out-of-bounds write in the Brotli decoder also known as Broccoli2Shell, Node2Shell and HTTP2Shell.
- Applications are affected if they opt in to Brotli decompression through ASP.NET Core, HttpClient or the System.IO.Compression Brotli APIs, and the updates cover .NET 8, .NET 9, .NET 10 and .NET 11 Release Candidate 3.
- PoC exploits have been published on GitHub but no malicious exploitation has been reported, and those who cannot update should block incoming Brotli-compressed requests or disable Brotli decoding.

**번역**

- 마이크로소프트가 Broccoli2Shell, Node2Shell, HTTP2Shell로도 불리는 브로틀리 디코더의 치명적 범위 밖 쓰기 결함 CVE-2026-111497을 고치는 닷넷 긴급 보안 업데이트를 배포했다.
- ASP.NET Core, HttpClient, System.IO.Compression 브로틀리 API로 브로틀리 압축 해제를 직접 켠 애플리케이션이 영향을 받으며, 업데이트는 .NET 8, .NET 9, .NET 10과 .NET 11 Release Candidate 3을 대상으로 한다.
- 깃허브에 PoC 익스플로잇이 공개됐지만 악의적 악용 보고는 없으며, 바로 업데이트할 수 없으면 들어오는 브로틀리 압축 요청을 차단하거나 브로틀리 디코딩을 꺼야 한다.
