## 2. Attackers hijack Microsoft’s agent-framework package to steal Azure and CI credentials

- **번역 제목**: 공격자들, Azure 및 CI 자격 증명 탈취 위해 마이크로소프트의 agent-framework 패키지 하이재킹
- **날짜**: 2026-11-18 21:03 KST
- **주제**: 에이전트, 개발, 보안
- **중요도**: 9/10 - 에이전트 개발자는 패키지 버전 검증 및 탈취된 토큰 즉시 재발급
- **태그**: 부정
- **출처**: InfoWorld
- **링크**: [원문 기사](https://www.infoworld.com/article/4250167/attackers-hijack-microsofts-agent-framework-package-to-steal-azure-and-ci-credentials-2.html)

**요약**

- Attackers briefly hijacked Microsoft's Agent Framework package on PyPI to distribute credential-stealing malware.
- The malicious versions automatically harvested cloud tokens, CI/CD credentials, and developer secrets across build pipelines and developer systems.
- The packages targeted AI developer pipelines before being removed within an hour, and unpinned builds created during that window may remain exposed.

**번역**

- 공격자들이 자격 증명 탈취 악성코드를 유포하기 위해 PyPI에 등록된 마이크로소프트의 공식 Agent Framework 패키지를 일시적으로 하이재킹했다.
- 악성 버전들은 빌드 파이프라인과 개발자 시스템 전반에서 클라우드 토큰, CI/CD 자격 증명, 개발자 비밀 정보를 자동으로 수집했다.
- 해당 패키지는 1시간 이내에 삭제되기 전까지 AI 개발자 파이프라인을 표적으로 삼았으며, 해당 시간 동안 버전을 고정하지 않고 빌드된 환경은 여전히 노출되어 있을 수 있다.
