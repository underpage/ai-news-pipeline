- **링크**: [원문 기사](https://thehackernews.com/2026/11/amazon-uncovers-ai-agent-campaign.html)

**요약**

- Amazon's threat intelligence team uncovered an attack campaign where AI agents targeted internet-exposed AI applications such as LiteLLM and Dify to steal stored AI provider API keys.

- 해당 공격자 에이전트는 오픈소스 침투 테스트 도구인 ARTEX 기반의 중국 연계 그룹으로 중간 수준의 신뢰도로 평가되었으며, 탈취한 키를 사용해 여러 플랫폼에서 추가 키 탐색을 수행했다.
- 이 캠페인은 취약한 관리자 설정, 기본 자격 증명, 여러 AI 프레임워크의 결함을 악용해 프리미엄 AI 모델 접근 권한을 공유 풀에 축적했다.

## 5. New NoisyTCP vulnerability lets attackers crash Linux servers

- **번역 제목**: 새로운 NoisyTCP 취약점으로 인해 공격자가 리눅스 서버를 다운시킬 수 있음
- **날짜**: 2026-11-16 18:30 KST
- **주제**: 보안
- **중요도**: 8/10 - 리눅스 커널 기반 전 서버 긴급 패치 필요
- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/linux/new-noisytcp-linux-kernel-flaw-lets-attackers-crash-servers/)

**요약**

- A 11-year-old Linux kernel TCP networking flaw dubbed NoisyTCP (CVE-2026-99288) allows unauthenticated remote attackers to trigger kernel panics and crash servers.
- The flaw stems from a NULL pointer dereference caused by a race condition during lockless socket lookups when handling SYN cookies and socket hashing under specific network traffic conditions.
- Although a patch has been merged into the mainline Linux kernel, systems that cannot immediately upgrade are advised to disable SYN cookies and serialize traffic to a single RX queue as mitigations.

**번역**

- NoisyTCP(CVE-2026-99288)로 명명된 11년 된 리눅스 커널 TCP 네트워킹 결함으로 인해 인증되지 않은 원격 공격자가 커널 패닉을 유발해 서버를 다운시킬 수 있다.
- 이 결함은 특정 네트워크 트래픽 조건에서 SYN 쿠키 처리와 소켓 해싱 중 락리스 소켓 조회 간의 경쟁 조건으로 인해 발생하는 널 포인터 역참조에서 기인한다.
- 메인라인 리눅스 커널에 이미 패치가 병합되었지만 즉시 업그레이드할 수 없는 시스템의 경우 완화책으로 SYN 쿠키를 비활성화하고 트래픽을 단일 RX 큐로 직렬화할 것을 권고한다.

- **태그**: 부정

- **링크**: [원문 기사](https://www.helpnetsecurity.com/2026/11/16/geovision-camera-software-vulnerabilities/)

**요약**

- Attackers leveraged internet-exposed GeoVision camera management software to breach Windows systems at 13 organizations and deploy cryptocurrency miners.
- After gaining access via outdated GV-VMS software containing unauthenticated remote code execution vulnerabilities, the actors disabled Microsoft Defender using BYOVD techniques and IFEO hijacking.
- The custom loader utilized BitTorrent DHT and PKARR resolvers to maintain infrastructure resilience, highlighting persistent risks associated with unpatched edge surveillance software.

**번역**

- 공격자들은 인터넷에 노출된 지오비전 카메라 관리 소프트웨어를 악용해 13개 기관의 윈도우 시스템을 침해하고 암호화폐 채굴 프로그램을 설치했다.
- 인증되지 않은 원격 코드 실행 취약점이 포함된 구형 GV-VMS 버전을 통해 침투한 공격자들은 BYOVD 기법과 IFEO 하이재킹을 사용해 마이크로소프트 디펜더를 무력화했다.
- 해당 커스텀 로더는 인프라 복원력을 유지하기 위해 비트토렌트 DHT와 PKARR 리졸버를 활용했으며, 이는 패치되지 않은 엣지 감시 소프트웨어의 지속적인 보안 위험을 보여준다.
