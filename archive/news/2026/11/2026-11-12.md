## 4. Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely

- **번역 제목**: 치명적인 Apache HTTP/2 결함, 인증되지 않은 공격자의 원격 코드 실행 가능
- **날짜**: 2026-11-12 14:12 KST
- **주제**: 개발, 보안
- **중요도**: 8/10 - 아파치 HTTP/2 서버는 2.4.71로 갱신 필요
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html)

**요약**

[수동 요약]

- A critical flaw in Apache HTTP Server's mod_http2 module, tracked as CVE-2026-119618, can let a remote attacker run code on the server.
- It affects versions 2.4.55 through 2.4.70 with HTTP/2 enabled, and Red Hat rates it 9.8 out of 10 on the CVSS scale.
- It is fixed in version 2.4.71, and admins who cannot update yet can remove h2 and h2c from the Protocols directive, as Wiz advises.

**번역**

- Apache HTTP Server의 mod_http2 모듈에서 CVE-2026-119618로 추적되는 치명적 결함이 발견되어 원격 공격자가 서버에서 코드를 실행할 수 있다.
- HTTP/2를 활성화한 2.4.55부터 2.4.70까지의 버전이 영향을 받으며, Red Hat은 이 결함을 CVSS 10점 만점에 9.8로 평가했다.
- 2.4.71에서 수정되었고, 아직 업데이트할 수 없는 관리자는 Wiz의 권고대로 Protocols 지시문에서 h2와 h2c를 제거할 수 있다.
