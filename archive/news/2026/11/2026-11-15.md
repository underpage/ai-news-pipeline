## 1. Cursor confirms security breach led to malicious Claude Code extension

- **번역 제목**: Cursor, 악성 Claude Code 확장 유포로 이어진 보안 침해 확인
- **날짜**: 2026-11-15 02:27 KST
- **주제**: 개발, 보안
- **중요도**: 9/10 - AI 개발 도구 마켓플레이스 침해를 통한 악성 확장 유포
- **태그**: 부정
- **출처**: BleepingComputer
- **링크**: [원문 기사](https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/)

**요약**

- Cursor confirmed a security breach where attackers stole credentials from AI provider Fireworks AI to access internal systems and distribute a malicious Claude Code extension through its marketplace.
- The exposed data included historical AI coding-agent traces with unredacted credentials, allowing hackers to compromise SaaS tools and publish backdoored extensions that targeted up to 5,000 developers.
- Cursor revoked the compromised keys, rotated credentials, and removed the malicious builds after 11 hours, though coding errors likely prevented the SSH backdoor from executing on many systems.

**번역**

- Cursor는 공격자가 AI 제공업체 Fireworks AI에서 탈취한 자격 증명으로 내부 시스템에 접근해 마켓플레이스를 통해 악성 Claude Code 확장을 유포한 보안 침해를 확인했다.
- 노출된 데이터에는 삭제되지 않은 자격 증명이 포함된 과거 AI 코딩 에이전트 추적 기록이 포함되어 있었으며, 해커는 이를 이용해 SaaS 도구를 침해하고 최대 5,000명의 개발자를 표적으로 한 백도어 확장을 게시했다.
- Cursor는 침해된 키를 취소하고 자격 증명을 교체한 뒤 11시간 만에 악성 빌드를 삭제했으나, 코딩 오류로 인해 많은 시스템에서 SSH 백도어가 실행되지 않았을 가능성이 있다.

- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/11/attackers-exploit-unrealircd-flaw-that.html)

**요약**

- CISA added a high-severity command injection vulnerability impacting the UnrealIRCd open-source IRC server to its Known Exploited Vulnerabilities catalog following reports of active attacks.
- Tracked as CVE-2026-114713 with a CVSS score of 8.6, the flaw stems from improper delimiter neutralization in the labeled-response module, allowing users to execute commands with server privileges.
- Active exploitation began shortly after the release of version 6.2.7.1, prompting maintainers and authorities to urge administrators to apply hotpatches immediately.

**번역**

- CISA는 실제 공격 사례가 보고됨에 따라 UnrealIRCd 오픈소스 IRC 서버에 영향을 미치는 고위험 명령 삽입 취약점을 알려진 악용 취약점 카탈로그에 추가했다.
- CVE-2026-114713(CVSS 점수 8.6)으로 추적되는 이 결함은 라벨 응답 모듈의 구분 기호 처리 미흡으로 인해 발생하며, 사용자가 서버 권한으로 명령을 실행할 수 있도록 허용한다.
- 6.2.7.1 버전 핫픽스가 배포된 직후부터 실제 악용 시도가 시작되어 관리자와 당국은 즉시 패치를 적용할 것을 촉구했다.
