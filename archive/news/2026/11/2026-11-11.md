- **주제**: 개발, 보안
- **중요도**: 9/10 - 재귀적 복제 시 악성 코드 실행되는 깃 심각 취약점 패치
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html)

**요약**

- The Git project patched a critical vulnerability tracked as CVE-2026-111760 that allows malicious repositories to execute attacker code during recursive clones with submodules.
- The flaw stems from an integer truncation in path handling that lets an attacker replace a submodule's .git file with a symbolic link to execute malicious hooks.
- GitHub has deployed fixes across its hosted environments and recommends updating all Git installations and avoiding recursive clones from untrusted sources.

**번역**

- 깃 프로젝트는 서브모듈과 함께 재귀적 클론을 수행하는 동안 악성 저장소가 공격자 코드를 실행할 수 있는 CVE-2026-111760 취약점을 패치했다.
- 이 결함은 경로 처리 과정의 정수 절삭으로 인해 발생하며, 공격자가 서브모듈의 .git 파일을 심볼릭 링크로 대체해 악성 훅을 실행할 수 있도록 한다.
- 깃허브는 호스팅 환경 전반에 패치를 적용했으며 모든 깃 설치본을 업데이트하고 신뢰할 수 없는 소스로부터의 재귀적 클론을 피할 것을 권고했다.
