## 2. Java4Shell (CVE-2026-114938) Enables Pre-Auth RCE in Jira, Jenkins, Keycloak on Java 17+ AVX-512 VBMI Servers

- **번역 제목**: Java4Shell (CVE-2026-114938), AVX-512 VBMI 서버의 Java 17+ 환경에서 Jira, Jenkins, Keycloak의 사전 인증 RCE 가능하게 해
- **날짜**: 2026-11-18 13:27 KST
- **주제**: 개발, 보안, 신기술
- **중요도**: 8/10 - 인프라 운영자는 AVX512 환경의 오픈JDK 긴급 패치 필요
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/11/java4shell-cve-2026-114938-enables-pre.html)

**요약**

- A flaw tracked as CVE-2026-114938 and dubbed Java4Shell allows unauthenticated remote attackers to execute code or trigger crashes on applications like Jira, Jenkins, and Keycloak running on Java 17+ with AVX-512 VBMI support.
- The vulnerability stems from an out-of-bounds write in Java's optimized Base64 decoder when processing malformed strings with an extra equal sign, enabling memory manipulation through an attack technique called JavaBleed.
- Oracle, OpenJDK, and Amazon have released security fixes for their builds, and infrastructure operators using affected hardware must urgently apply patches.

**번역**

- CVE-2026-114938로 추적되고 Java4Shell이라 불리는 결함은 인증되지 않은 원격 공격자가 AVX-512 VBMI를 지원하는 Java 17 이상 환경의 Jira, Jenkins, Keycloak 등 애플리케이션에서 코드를 실행하거나 충돌을 일으킬 수 있게 한다.
- 이 취약점은 여분의 등호가 포함된 잘못된 형식의 문자열을 처리할 때 Java의 최적화된 Base64 디코더에서 발생하는 범위를 벗어난 쓰기에서 비롯되며, JavaBleed라는 공격 기법을 통한 메모리 조작을 가능하게 한다.
- 오라클, OpenJDK, 아마존은 자사 빌드에 대한 보안 패치를 배포했으며, 영향을 받는 하드웨어를 사용하는 인프라 운영자는 긴급히 패치를 적용해야 한다.
