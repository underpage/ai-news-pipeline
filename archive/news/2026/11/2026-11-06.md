- **중요도**: 8/10 - 챗GPT의 프롬프트 주입 방어 모드 우회 및 대화 탈취 취약점
- **태그**: 부정
- **출처**: The Hacker News
- **링크**: [원문 기사](https://thehackernews.com/2026/11/researchers-bypass-chatgpt-lockdown.html)

**요약**

- Cybersecurity researchers disclosed a patched vulnerability in ChatGPT that allowed attackers to bypass Lockdown Mode and exfiltrate chat data without user interaction.
- The flaw exploited nested sandboxed frames within HTML page previews, permitting popups to escape the sandbox and bypass outbound network restrictions.
- This finding demonstrates that vulnerabilities in the broader application environment outside the AI model can compromise and undermine AI security controls.

**번역**

- 사이버 보안 연구원들이 공격자가 사용자 상호작용 없이 잠금 모드를 우회하고 대화 데이터를 유출할 수 있는 ChatGPT의 패치된 취약점을 공개했다.
- 해당 결함은 HTML 페이지 미리보기 내부의 중첩된 샌드박스 프레임을 악용해 팝업이 샌드박스를 벗어나 아웃바운드 네트워크 제한을 우회하도록 허용했다.
- 이 발견은 AI 모델 외부의 광범위한 애플리케이션 환경에 존재하는 취약점이 AI 보안 통제를 무력화하고 침해할 수 있음을 보여준다.
