- **태그**: 중립
- **링크**: [원문 기사](https://techcrunch.com/2026/08/05/meta-launches-muse-code-an-ai-agent-for-large-code-bases/)

### 요약
- Meta has launched Muse Code, a new AI terminal coding agent designed to assist programmers with complex tasks across large software code bases.
- Powered by Meta's Muse Spark, it can perform complete software engineering tasks like planning, writing code, and validating results, utilizing parallel sub-agents for big projects.
- This release aims to position Meta more competitively and affordably against AI lab peers such as OpenAI's Codex and Anthropic's Claude Code.

### 번역
- 메타는 대규모 소프트웨어 코드베이스의 복잡한 작업을 돕는 새로운 AI 터미널 코딩 에이전트 '뮤즈 코드'를 출시했습니다.
- 메타의 뮤즈 스파크 기반인 이 에이전트는 계획, 코딩, 결과 검증 등 완전한 소프트웨어 엔지니어링 작업을 수행하며, 대규모 프로젝트에는 병렬 하위 에이전트를 활용합니다.
- 이번 출시는 OpenAI의 Codex나 Anthropic의 Claude Code 같은 경쟁사들에 비해 AI 에이전트 시장에서 메타의 경쟁력과 비용 효율성을 높이려는 전략입니다.
